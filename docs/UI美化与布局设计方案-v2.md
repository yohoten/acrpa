## 2. 诊断：6 项布局问题（按 ROI 排序）

### L1 · 参数列等宽分配与实际元数严重错配 —— 最高 ROI

**量化事实**（程序化统计 `commands.schema()`，68 条命令）：

| 参数个数 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 9 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 命令数 | 9 | 21 | 17 | 8 | 4 | 3 | 2 | 3 | 1 |

- 加权平均元数 **2.24**
- **≤2 参数：47/68（69%）**；**≥5 参数：仅 9/68（13%）**；元数 9 仅「区域点图」1 条

**UI 现状**（`ACRPA.py:4174-4178`）：

```python
tree.heading("#0",  text="#");       tree.column("#0",  width=32,  minwidth=32)
tree.heading("cmd", text="命令类型"); tree.column("cmd", width=100, minwidth=80)
for i in range(1, 10):
    tree.heading(c, text="参数{}".format(i)); tree.column(c, width=65, minwidth=50)
```

固定占用 = 32 + 100 + 9×65 = **717 px**，且 `stretch` 未设（默认 0）→ 列宽不随窗口伸缩。

**后果**：

1. **空单元格浪费**：典型行（找图，2 参数）有 7 个空列，屏幕 585px 用于显示空白。
2. **横滚常驻**：`win_min_w=640` < 717 → 最小窗口下必然横向滚动。
3. **语义丢失**：列头是 `参数1..参数9`，而 schema 已知真实名 —— 例如「区域点图」= `图片名/精度/左/上/宽/高/灰度/按键/次数`（已验证）。
4. **编辑面不一致**：主表格内联编辑是**通用 `Entry`**（`_edit_cell():2746-2776`），而 `param_form` 的具名表单只在 **F2 对话框**与**工作流节点**两处使用 —— **最强的编辑能力藏在最深的入口**。

### L2 · 双标题栏并存（垂直空间冗余 + 语义重复）

- `root` **未** `overrideredirect`（全库仅 Recording Bar `ACRPA.py:377` 与 tooltip `Toplevel` 用了该标志）→ **原生标题栏仍在**，显示 `root.title("A/C RPA")`（`:3955`）。
- 同时 `row0` 有**自绘标题栏**（`:4030`），显示 `"A/C RPA Automation Workflow"`（`:4034`）+ 6 个图标按钮 + 1px 发丝线（`:4064`）。

→ 应用名**出现两次**，自绘栏占用约 30px 垂直空间。

> 注：自绘栏文案可双击编辑（`_start_title_edit():1149`），其语义本应是「**文档标题**」（类似编辑器文件名），但默认值填了应用名，才与原生栏冲突。**问题在默认值，不在自绘栏本身**。

### L3 · 跨窗口布局纪律断裂

| 文件 | 行数 | `utils.sp()` / `TOKENS` / `ctrl_h()` 命中 |
| --- | --- | --- |
| `src/netlink_window.py` | 3606 | **0** |
| `src/dialogs.py` | 1525 | **0** |
| `src/help_window.py` | 1010 | **0** |
| `src/market_window.py` | 1810 | 3 |
| `src/ui/settings/window.py` | 631 | 3 |
| `src/ACRPA.py`（主窗） | 4556 | 全面消费 |

→ 主窗口已 token 化，**从窗口仍用字面量布局**。同一应用存在两套尺度语言；`set_ui_scale()` 对从窗口基本无效。

### L4 · 缺响应式断点

仅有「工具条横向溢出滚动」（L1 已述）一项自适应。**无宽度断点策略**：`win_min_w=640` 下表格必然横滚，且无「窄屏降级」形态。

### L5 · 图例条常驻占用编辑区

`legend_frame` 位于 `tab_edit` 的 `row=2`（`ACRPA.py:4199-4212`），6 组「色点 + 标签」**无条件常驻**，与当前脚本是否含该类别命令无关。在 680px 高的默认窗口中持续占用编辑区垂直空间。

### L6 · 旧文档引用大面积失效

见 §0 表格。`settings_window.py` 全篇路径失效；`ACRPA.py` 从 5738 → 4556 行，旧 `:4xxx` 锚点几乎全部漂移；`utils.py` 的 `TOKENS` 已移到 `:832`（旧记 `:731`）。

## 3. 布局设计方案

### 3.1 标题栏：语义分离（L2）

三个方案对比：

| 方案 | 做法 | 收益 | 成本 / 风险 |
| --- | --- | --- | --- |
| **A 全自绘** | `root.overrideredirect(True)`，去掉原生栏；自绘栏补齐最小化/最大化/关闭与拖拽 | 视觉完全统一，品牌感最强 | **高**：需自实现窗口拖拽、双击最大化、系统菜单、任务栏缩略图；与 `WM_SETICON` / DPI 逻辑有交互 |
| **B 移除自绘** | 删 `row0`，图标组并入执行控制栏右侧 / 状态栏 | 回收 30px；零自绘成本 | 中：失去可双击改名的文档标题位 |
| **C 语义分离**（推荐） | 保留两栏，但**自绘栏默认文案改为「当前脚本名」**（空则「未命名脚本」），原生栏保留应用名 | **零结构改动**消除重复；自绘栏获得真实用途（文档标题） | **低**：改默认值 + 脚本切换时同步刷新 |

**推荐 C**。改动落点：

- `TITLE_DEFAULT_TEXT`（`ACRPA.py:1116`）→ `"未命名脚本"`
- `build_app()` 中 `title_lbl` 初值（`:4034`）
- 在 `_cmd_open` / `_cmd_save_as` / `select_script` 后同步 `title_lbl.config(text=...)`
- A 方案列入阶段三可选（若后续要做 Fluent 风格统一标题栏）

### 3.2 脚本表重构（L1）—— 核心

三方案对比：

| 方案 | 形态 | 优 | 劣 |
| --- | --- | --- | --- |
| 1 具名动态列 | 按当前脚本命令并集生成具名列（图片名/精度/左/上…） | 语义化；保留网格扫描 | 列数仍可达 9；跨类型行仍大量空；列集随脚本变化，跳动 |
| 2 固定 3 列 + 详情面板 | `#` / 命令 / 参数摘要 + 侧/下具名面板 | 列少、天然响应式、复用 `param_form` | 失去网格整体扫视能力 |
| **3 混合（推荐）** | 默认**紧凑视图** 4 列；F2/双击打开具名面板；保留「表格视图」开关切回 p1..p9 网格 | 兼顾可读与批量核对；渐进迁移 | 需维护两种渲染 |

**推荐方案 3**。紧凑视图列定义：

| 列 | 内容 | 宽度策略 |
| --- | --- | --- |
| `#` | 行号 + 断点 `●` + 当前行 `◀` | 32 固定（沿用） |
| 命令 | 命令名（含分类色点） | `minwidth=120, stretch=1` |
| 参数摘要 | 由 schema 渲染：`图片名=btn.png · 精度=0.96`，空值省略 | `minwidth=200, stretch=3` |
| 备注 | 注释 / 禁用标记 | `minwidth=80, stretch=0`（窄屏隐藏） |

参数摘要渲染规则（纯函数，易测）：

```python
def arg_summary(cmd_type, args):
    """按 schema 参数名渲染 '名=值'，空值跳过；全部为空返回 ''。"""
    ps = commands.schema(cmd_type) or []
    parts = []
    for i, p in enumerate(ps):
        v = (args[i] if i < len(args) else "").strip()
        if v and v != "None":
            parts.append("{}={}".format(p.get("name", "p%d" % (i + 1)), v))
    return " · ".join(parts)
```

> 复用点：`ui/param_form.py` 已有 `args_to_schema_values` / `schema_values_to_args`（`:79/:100`），摘要渲染应置于同模块，避免第二处 schema 解析。

**编辑入口**（保持现有习惯，只增强）：

- **双击** → 保持内联编辑（`_edit_cell`），但参数摘要列改为打开**具名弹层**（复用 `param_form.build_arg_form`）
- **F2** → 具名对话框（已有，`:1914`）
- **表格视图开关** → 工具条 `▦` 按钮，切回 p1..p9 网格（供批量核对 / 粘贴 Excel）

### 3.3 响应式断点表（L4）

| 断点 | 窗口宽度 | 行为 |
| --- | --- | --- |
| **L** | ≥ 1100 | 全列（含备注）；图例条展开 |
| **M** | 720 – 1100 | 隐藏「备注」列；图例条收起为 `◍` 气泡按钮 |
| **S** | 560 – 720 | 参数摘要按列宽截断 + tooltip 全文；工具条溢出滚动（已有） |
| **XS** | < 560 | **卡片列表模式**：禁用 Treeview，改 Frame 行（命令名一行 + 参数摘要一行），键盘导航保留 |

实现：绑定 `root <Configure>`，按 `winfo_width()` 查表切换；切换需防抖（≥150ms）避免拖窗抖动。

### 3.4 多窗口布局收口（L3）

新增 `src/ui/layout.py`，提供四个工厂（全部消费 `TOKENS`/`sp()`）：

| 工厂 | 职责 |
| --- | --- |
| `page(parent, title, actions=None)` | 标准页容器：标题条（`surface_alt` 底 + 1px 下发丝线 + 标题 + 右工具）+ 内容 + 底栏 |
| `toolbar(parent, groups)` | 分组命令栏：组间 1px 竖线 + 溢出 `⇄`（复用 `ACRPA.py:4134` 的 canvas 思路） |
| `split(parent, panes, orient)` | 封装 `PanedWindow` + `minsize` + 一键收起 |
| `form_row(parent, label, widget)` | 标签-控件行，标签列宽对齐（消除从窗口各自 `padx` 魔法数） |

**推行策略**：不一次性重写存量。规则是 —— **从窗口的任何新增/重构改动必须走工厂**；存量按 L-C 期分批替换，优先级 `netlink_window`（3606 行、0 命中、且仍在活跃开发）> `dialogs` > `market_window` > `help_window`。

### 3.5 图例条按需显示（L5）

- 默认**收起**为工具条右侧 `◍ 图例` 按钮，点击弹出浮层
- 若展开，**仅显示当前脚本中出现过的命令类别**（扫描 `state._editor_rows` 的命令类型集合）
