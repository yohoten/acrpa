> 定位：v1 定「皮肤语言」、v2 定「布局诊断」、v3 定「布局 + 细节 + 性能」、v4 定「视觉层级 · 分类色 · 一致性收口」。

## 1. 现状基线（实证，2026-11-07）

### 1.1 主窗口四行骨架

主窗口 `root` 用 `grid` 分 4 行（`src/ACRPA.py:6393-6399`）：

| row | 区域 | 容器 | 说明 |
| --- | --- | --- | --- |
| 0 | 自绘标题栏 `title_bar` | Frame | 左：文档标题（双击改名）；右：状态点 / 置顶 / 折叠 Mini Bar / 深浅色 / 设置 / 帮助 |
| 1 | 执行控制工具栏 `exec_bar` | `ui_exec_bar.build()` | **原「执行控制」Tab 降级为常驻工具栏**，跨 Tab 共用 |
| 2 | 主区 `main_paned` | **垂直** `PanedWindow` | 上 pane = Notebook；下 pane = 常驻日志 Dock |
| 3 | 状态栏 `status_bar` | Frame | 状态文案 / 控制信息 / 进度条 / 日志展开入口 |

Mini Bar 是折叠后的独立形态（`src/mini_bar.py`），由 `_toggle_fold` / `_bind_minibar()` 触发（`src/ACRPA.py:6427-6431`、`6876-6878`）。

### 1.2 Notebook 四大 Tab 与懒构建

Notebook 建在 `main_paned` 内（`src/ACRPA.py:6473-6474`），Tab 顺序：

| # | Tab | 构建时机 | 内容 |
| --- | --- | --- | --- |
| 1 | 脚本编辑 | 启动立即 | 表格式脚本编辑器（树 + 横向工具栏 + 图例），**无 PanedWindow** |
| 2 | 工作流 | 懒构建 `_build_workflow_tab` | 外层横 Paned（操作库 ↔ 右半区）+ 内层横 Paned（步骤树 ↔ 流程图） |
| 3 | 设备互联 | 懒构建 `_build_devlink_tab` | 内嵌 NetLink（`host=tab_devlink`），否则独立 `Toplevel` |
| 4 | 定时任务 | 懒构建 `_build_sched_tab` | 顶部入口 + 左右 Paned + 底部折叠日志 |

「执行控制」不再是 Tab（降级为 row 1 常驻工具栏）；「设置」从 Tab 分离为独立窗口 `settings_window.open_settings_window`。Tab 切换由 `<<NotebookTabChanged>>` → `_on_wf_tab_changed` 驱动，并同步 `ui_exec_bar.set_active_tab(0/1)` 切换执行栏形态（`src/ACRPA.py:6816-6834`）。

### 1.3 主题 / 缩放 / 换肤体系

- **颜色唯一真源**：`ui.theme.colors(dark)`，明暗双套色板（`src/ui/theme.py:62-117`）。
- **字体角色**：`FONT_*` 为命名字体（`ACRPA_TITLE/BODY/LOG/SMALL/...`），规格在 `utils._FONT_SPECS`；`init_fonts(root)` 创建/重配，字号走 `fit_pt()`。
- **UI 缩放**：`state.UI_SCALE` → `current_ui_scale()`；`sp(key_or_px)` 统一走 `scaled()`（`round(value * dpi_factor() * ui_scale)`）；`ctrl_h()` 取控件高；`dpi_factor()` 基于 `winfo_fpixels("1i")/96`。
- **换肤**：`ui.theme.subscribe(fn)` / `publish(dark, colors, prev)` 组成 ThemeBus；通用重刷走 `_refresh_theme()` 的递归 `_walk()`（按 `winfo_class()` 分派）；语义角色 `set_role(widget, token)` 在创建处登记，`_walk` 按角色回填、不嗅探文案。独立窗口用 `claim_window()` 声明「自管换肤」。

### 1.4 现有交互原语

| 原语 | 实现 | 位置 |
| --- | --- | --- |
| 防抖 | `_debounce_cb(widget, key, ms, fn)`（`after_cancel`） | `src/ACRPA.py:662-689` |
| 行悬停 | `_bind_row_hover(tree)`（`rowhover` tag） | `src/ACRPA.py:1850-1885` |
| 选中加粗 | `_bind_sel_bold` / `utils.bind_sel_bold` | `src/utils.py:706-734` |
| Toast | `utils.show_toast`（单例 Toplevel + 淡入/位移） | `src/utils.py:95-160` |
| Tooltip | `utils.attach_tooltip`（字符串/ callable，延迟 400ms） | `src/utils.py:604-631` |
| 图标键盘可达 | `utils.bind_icon_activate`（`<Return>/<space>` + 焦点环 + 可访问名） | `src/utils.py:673-703` |
| 快捷键 | Tab 感知 `Ctrl+S/N/O` 经 `bind_all` | `src/ACRPA.py:6883-6912` |
| 按钮 hover | `_tbtn()` `<Enter>/<Leave>` 双变化 | `src/ACRPA.py:4793-4803` |

**结论**：骨架（四行）、容器（Notebook + 垂直 Paned）、换肤（ThemeBus + 角色）、交互原语都已成型。问题是**分栏规则、折叠体验、拖拽记忆、高频操作的卡顿治理**尚未全局统一——这正是本文要收口的部分。

## 2. 设计原则（布局 / 交互六条）

1. **区域要有归属，不要平铺。** 常驻操作上工具栏（row 1），跨 Tab 内容进 Notebook（row 2 上 pane），诊断输出进底部 Dock（row 2 下 pane），全局状态进状态栏（row 3）。
2. **分栏用 PanedWindow，不用写死像素。** 凡「两栏或多栏可调」一律 `ttk.PanedWindow`；给 `minsize` + `weight` + 初次 `sashpos` 比例，并持久化用户拖拽结果。
3. **高频变更只做轻量动作。** 开关/筛选/拖动这类高频事件，只更新「当前运行态」，写盘与调度重启用防抖（`after_cancel` + `after`）合并，绝不每帧全量重建。
4. **能折叠就折叠，但折叠要可发现。** 日志、侧栏等「次要但可诊断」区域，默认给一条标题/工具条，切换只隐藏表体、保留操作入口。
5. **键盘与鼠标等价可达。** 图标按钮都要有 `<Return>/<space>` 激活、焦点环与可访问名；树表要有行悬停 + 选中加粗两种反馈。
6. **主题/缩放一处变，处处变。** 新 UI 一律从 `C[...]` / `sp()` / `FONT_*` 取值，并在创建处登记语义角色 `set_role`；不写死色值、字号、像素间距。

## 3. 方案：全局布局优化

### 3.1 四行骨架的边界固化（P0）

现状四行是对的，但需要把「哪些东西能上 row 1、哪些只能进 Tab」写死，避免再次出现「执行控制既当 Tab 又当工具栏」的摇摆。

| 区 | 可放 | 不可放 |
| --- | --- | --- |
| row 0 标题栏 | 窗口级：标题、状态点、置顶/折叠/主题/设置/帮助 | Tab 业务按钮 |
| row 1 执行栏 | **跨 Tab 共用的执行控制**：启动/停止/循环/单步 + 当前 Tab 形态切换 | Tab 私有工具栏 |
| row 2 上 pane（Notebook） | 各 Tab 工作区 | 全局诊断输出 |
| row 2 下 pane（日志 Dock） | 运行日志/执行记录（全局诊断） | Tab 私有设置 |
| row 3 状态栏 | 状态、进度、日志展开入口 | 可点主操作 |

**收益**：新同事/新 AI 接活时，不用猜「这按钮该放哪」——先看它属于窗口级、执行级、工作区级、诊断级、状态级中的哪一级。

### 3.2 主区 Paned 与 Dock 的权重/伸缩策略（P1）

现状 `main_paned` 是垂直 Paned，日志 Dock `minsize=60, height=160, stretch="never"`。问题：**Dock 拉伸策略是「从不」，导致窗口拉高时日志不会分到额外高度**，大屏上日志永远 160px，反而浪费。

| 项 | 现状 | 建议 |
| --- | --- | --- |
| Notebook pane | 默认 stretch | `weight=1, stretch="always"` |
| 日志 Dock pane | `stretch="never"` | 改为 `weight=0, stretch="always", minsize=60`；初始 `sashpos` 设在「窗口高 − 180」 |
| 收起行为 | 一键收起（`log_dock_toggle_btn`） | 保持，但收起时 `sash` 位置要记忆，展开时恢复 |

> 语义：`weight` 决定「窗口变大时多出来的空间分给谁」，`stretch` 决定「pane 是否随整体等比缩放」。Dock 应 `weight=0`（不给增量）+ `stretch=always`（跟随窗口等比），而不是 `stretch=never`（完全僵死）。

### 3.3 Notebook Tab 信息架构与懒构建（P1）

现状 4 Tab：脚本编辑、工作流、设备互联、定时任务；「执行控制」已常驻、「设置」已独立。信息架构是合理的，剩余两件事：

1. **懒构建幂等性**：`_build_*_tab` 已用 `_*_LAZY["built"]` 幂等保护，但异常只记一次、不重试（`built=True` 先置位再 try）。建议失败时 `built=False`，下次切 Tab 重试一次，避免「一次资源缺失导致该 Tab 永久空白」。
2. **Tab 切换同步**：`set_active_tab(0/1)` 目前只区分「工作流 vs 其他」。建议显式传 Tab 索引枚举，避免未来新增 Tab 时 `0/1` 魔法数漂移。

### 3.4 分栏规范统一（PanedWindow 约定）（P0）

全局所有 `ttk.PanedWindow` 应遵循同一套约定（现状三处：`main_paned` 垂直、工作流两个水平、定时任务一个水平、设备互联一个水平）：

| 约定 | 值 | 说明 |
| --- | --- | --- |
| `sashwidth` | `utils.sp("sb_w")` | 与滚动条同宽，主题化 |
| `sashrelief` | `"flat"` | 不凸起 |
| `opaqueresize` | `False` | 拖拽时实时重排（现代感） |
| 初始比例 | `after_idle` + `sashpos()` | 首帧再设，避免宽度未就绪时 `winfo_width()` 为 0 |
| `minsize` | 左/右各 ≥ 300 | 防止拖死 |
| 用户拖拽 | `sashpos()` 读回 → 持久化 | 见 §5.4 |

**已落地回执**：
- 设备互联由「1 列多行」重构为「2 列（左 3 区 + 右日志）」水平 `PanedWindow`，初次按 75%/25% 设 `sash`（`src/ui/netlink/window.py`）。
- 定时任务由「左管理 + 右设置」水平 `PanedWindow` 承载，初次按 52%/48% 平衡（`src/ui/sched_tab.py:451-472`）。

### 3.5 底部日志 Dock 与折叠（P1）

`ui/log_dock.py` 与 `ui/sched_tab.py` 的「执行记录」是同一类「可折叠诊断面板」，应统一折叠交互：

| 状态 | 展示 | 交互 |
| --- | --- | --- |
| 展开 | 标题 + 工具条（级别/搜索/清空/导出）+ 日志体 | 工具条右侧「收起 ▲」 |
| 折叠 | **保留标题 + 工具条**（只隐日志体） | 按钮文案切「展开 ▼」，恢复 `grid()` 并触发一次刷新 |

**已落地回执**：定时任务底部「执行记录」已实现 `_wire_log_toggle` / `_toggle_log_panel`——折叠只 `grid_remove()` 表体、保留工具条与「收起/展开」按钮，展开时补一次 `refresh()`（`src/ui/sched_tab.py`）。

## 4. 方案：Tab 级布局

### 4.1 脚本编辑（P2）

现状为「表格式编辑器」：横向滚动工具栏 + `Treeview`（`#0` + `cmd` + `p1..p9`）+ 图例条，无 PanedWindow（`src/ui/editor_view.py:134-247`）。方向正确（RPA 脚本是表格数据，密度优先）。仅两项微调：

1. 图例条在窄窗口下换行时的组间距，从「混用 10/12」统一为 12（对齐 v4 §7.3）。
2. 工具栏溢出已用 `_debounce_cb` 防抖布局，保持；新增 Tooltip 提示被折叠的按钮（可发现性）。

### 4.2 工作流（P2）

现状「外层横 Paned（操作库 ↔ 右半区）+ 内层横 Paned（步骤树 ↔ 流程图）」结构正确。建议：操作库侧栏 `minsize` 120、默认 180 已合理，补 `sashpos` 记忆（§5.4）。

### 4.3 设备互联（已落地，回执）

`src/ui/netlink/window.py` 由「1 列多行」重构为「2 列」：

- 根 `rowconfigure(2, weight=1)` + 水平 `ttk.PanedWindow`；
- 左列 = 设备列表 / 详情 / 已配对 / 操控 / 远程指令 / 传输（6 区，纵向权重分配）；
- 右列 = 日志面板（常驻，`weight=1`）；
- `_init_sash()` 初次按 75% 设分隔条；嵌入（`host=tab_devlink`）与顶层窗口共用同一布局。

**收益**：原来「设备列表 → 详情 → 操控」一路下拉，日志在底部被挤出；现在日志常驻右侧、可拖拽调宽，操控区不再被日志打断。

### 4.4 定时任务（已落地，回执）

`src/ui/sched_tab.py` 完成两项重设计：

1. **入口重设计**：原「右栏启用开关」每次切换触发全量 `_apply_schedule`（重启调度器 + 全量写盘），造成卡顿。现提升为**顶部 Header**（全局开关 + 下次执行预览），开关走轻量 `_toggle_enabled`（只 `start/stop_scheduler` + 更新预览），写盘走 800ms 防抖 `_flush_save_config`。
2. **日志可折叠**：底部「执行记录」接入 `_wire_log_toggle`，保留工具条、折叠表体（见 §3.5）。

**收益**：开关切换不再卡顿；入口与「单个任务右键启停」的层级关系更清晰（全局开关 → 任务级开关）。

## 5. 方案：交互优化

### 5.1 防抖 / 节流统一（P0）

现状有 `_debounce_cb`（键值防抖）与散落各处的 `after_cancel` 模式。建议收敛为两档原语：

| 场景 | 原语 | 延迟 |
| --- | --- | --- |
| 设置/筛选/搜索等「值变更 → 应用」 | 防抖（同 key 只留最后一次） | 400–800ms |
| 布局 `<Configure>` / 工具栏重排 | 防抖 | 100ms |
| 开关/启停（只改运行态） | **轻量直调 + 独立写盘防抖** | 0ms 切换 / 800ms 写盘 |

**已落地回执**：定时任务启用开关已按第三档实现——`_toggle_enabled`（轻量启停）+ `_debounced_save_config`（800ms 只写盘），不再触发参数重启（`src/ui/sched_tab.py`）。

### 5.2 悬停 / 选中 / 键盘可达（P1）

- 所有 `Treeview` 统一挂 `bind_row_hover` + `bind_sel_bold`（现状 `dialogs`/`sched_tab` 已有，`workflow` 需补齐）。
- 图标按钮统一 `bind_icon_activate`（`<Return>/<space>` + 焦点环 + `set_accessible_name`）。
- 可折叠按钮文案要体现状态（「收起 ▲ / 展开 ▼」），不能是静态文字。

### 5.3 Toast / Tooltip / 快捷键（P1）

- Toast 已有单例淡入动画，保持；**高频操作成功不弹 Toast**（如单行选中、开关切换），只对「不可逆/跨模块」操作弹（保存、导出、重启调度器）。
- Tooltip 对「可折叠/可拖拽/图标按钮」统一补文案（发现性）。
- 快捷键维持 Tab 感知；新增「`Ctrl+E` 切执行栏、`Ctrl+\` 折叠日志 Dock」等高频键位需评估冲突后再定。

### 5.4 拖拽分栏位置持久化（P1）

现状 `sashpos()` 只用于初次设比例，用户拖完后**重启即丢**。建议：

1. 定义 `LAYOUT_SASH` 持久化键，按 `{tab: {pane_id: position}}` 存 `recent.json` 或 `config.json`。
2. 窗口关闭 / 切 Tab 时读 `sashpos()` 写入；构建后 `after_idle` 若命中缓存则 `sashpos(pos)` 恢复，否则用默认比例。
3. 兜底：缓存值越界（窗口变小）时，`sashpos` 自动 clamp 到 `minsize` 内。

### 5.5 卡顿治理（P0，已部分落地）

| 卡点 | 根因 | 治理 |
| --- | --- | --- |
| 定时任务启用开关 | 每次切换全量重启调度器 + 写盘 | `_toggle_enabled` 轻量启停 + 防抖写盘（已落地） |
| 日志高频刷新 | 无变化也整表重建 | `build_sched_log` 已有变化签名 `_log_sig`，无变化跳过 |
| 工作流/设备互联首帧 | 全量构建 | 懒构建 + `after_idle` 平衡分栏 |
