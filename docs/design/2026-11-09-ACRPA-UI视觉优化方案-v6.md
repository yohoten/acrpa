# ACRPA UI 视觉优化方案 v6（增量：按钮角色落地 + 全窗口专项）

> 日期：2026-11-09 ｜ 前置：v5 方案（2026-11-07）已定义设计令牌、按钮族（§5.1）、空态组件（§5.4），
> 本文档**不重复定义**，只做三件事：
> ① 把 v5 按钮族逐按钮映射到各窗口/Tab 的真实控件清单；② 补 v5 未覆盖的专项；
> ③ 给出可直接施工的分期与验收。
> 证据 = 2026-11-09 两批截图：四张主窗整窗（脚本编辑 / 工作流 / 设备互联 / 定时任务）
> + 两张特写（执行栏与两工具栏、设备互联远程控制条）+ 设置窗口 + 帮助窗口，共 10 张。

## 0. 结论先行（6 条）

1. **当前最大问题是「实色按钮泛滥」**：单屏饱和实色块 9+ 个（编辑工具栏 18 钮 5 色），
   主次不分；按 v5 §5.1 六类角色逐按钮降级后，同屏实色块 9→2（执行条「运行」+ 工具条「保存」）。
2. **危险色权重倒挂**：编辑工具栏尾部「●录制」「清空」双红实心，加上「−删除」同屏 3 个红实心；
   **录制并非破坏性操作**，不该用 danger 实心。全 app 红实心应只保留「停止（运行中）」一处。
3. **系统焦点虚线框破坏质感**：Tab 选中态出现 Tk 默认 dotted ring（「工作流」页签可见），
   需全局去除并重定义选中态（底部 2px 主色条 + 加粗）。
4. **空状态不统一**：各 Tab 三种空状态（logo 水印 / 弱灰字 / 完全空白），v5 §5.4 空态组件的
   覆盖清单需扩到设备表、任务表、操作库搜索无结果等 12 处。
5. **帮助窗口 markdown 未渲染**：正文出现 `**基础操作:**` 字面星号，标题用虚线下划线模拟——
   属可读性缺陷，优先级等同 P0。
6. **一处主题漏网**：设备互联「设备日志」Text 外框粗黑（正文级别配色已随主题）；
   另设置窗口左导航**分组标题与条目重名**（基础设置/常规、扩展与关于/扩展与市场/关于），层级混乱。
7. **标题栏职责错位**：英文标语 "Adaptive Control Automation Workflow" 占约 1/3 宽度（信息量≈0，
   且顶替了「文档名」的默认值）；低频的 ⚙设置/?帮助 图标占据右侧黄金位，高频状态型快捷
   （置顶/明暗/折叠）反而被挤在一起 → 设置/帮助移左改为**文字下拉**（§9）。

## 3. Tab 选中态与焦点环（修 E3）

- 现状：clam 主题 `Notebook.tab` 自带焦点虚线；选中/未选中仅靠底色区分，弱。
- 方案：
  1. 重写 `Notebook.tab` layout 去掉 focus dots 元素（`style.layout("Notebook.tab", ...)`，保留 padding/text）；
  2. 选中态 = 底色 `surface_alt` + **底部 2px accent 色条**（自定义元素或 1px Frame 模拟）+ 文字 `fgb` 加粗；
  3. 未选中 = 透明底 + `fgm` 文字；hover = `surface_alt@50%`。
- 验收：截图放大 3 倍无虚线像素；四页签选中态含 2px 色条。

## 4. 工具栏竖线分组（修 E4）

- 同组按钮间距 `sp(6)`，组间插入 1px 竖线（高 ~18px，`bd` 色，上下留 4px）；
- 组顺序按 §2.2/§2.3 表（编辑组 → 文件组 → AI 组 → 工具组；工作流：文件 → 编辑 → AI → 节点 → 危险）；
- 危险组（删除/清空）**恒排最右**，与主流程物理隔离。
- 落点：各工具条构建处插入 `tkinter.Frame(width=1, bg=C["bd"])`；不改按钮回调。

## 5. 各 Tab 专项

### 5.1 工作流 · 操作库树（修 E5）

- 图标按类别区分 4–5 种（Unicode 字形即可，沿用 `FONT_ICON`）：
  找图/找色=▣、区域=▭、键鼠=⌨ 系（→ 用现有图标字体等价字形）、文本=¶、控制流=⟳；
  不引入新资源文件。
- 树条目截断时补 `attach_tooltip` 全名提示（`item_full_name` 已有数据源，落点 `workflow_view.py` 树填充处）。
- 「最近使用」与树的分组：小标题加 `fg3` + 上方 `sp(4)` 间距，弱化到次级区域。

### 5.2 设备互联（修 E6）

- **设备日志 Text 接主题**：底 `logbg`、字 `logfg`、边 `bd` 1px、滚动条走 `SCROLLBAR_KW`
  （落点 `src/ui/netlink/window.py`，登记 refresh_theme 或 claim 自管换肤，与日志面板同法）。
- 设备表空态 → v5 §5.4 组件：「还没有已配对设备 / 在对方机器开启允许被发现… / [显示配对码]」
  （文案 v5 已给）。
- 进度条改 6px 细条（v5 P2 项顺带）。

### 5.3 定时任务（修 E7）

### 5.4 空态覆盖点扩充（v5 §5.4 P0-6 的增量）

在 v5 已列 8 处之外新增：设备表（§5.2）、定时任务表（§5.3）、操作库搜索无结果、
设备互联「远程指令/传输」两个子页。共 12 处，验收同 v5 P0-6（截图核对）。

- 空态提示中 `Ctrl+N` 等渲染为键帽样式：accent 描边小圆角块（Canvas 绘制或全角括号+accent 色
  的低成本方案二选一，实施时定）。

### 5.6 设置窗口（修 E12；v5 §7 的增量）

- v5 §7「自动保存 ▾ 只写一次」已见落地（底部状态条 ✓所有设置已自动保存），本节只补增量。
- **左导航重名治理**：分组标题（基础设置 / 自动化 / 智能与连接 / 扩展与关于）与其下首个条目
  语义重复或同名（基础设置→常规；扩展与关于→扩展与市场、关于）。方案二选一：
  ① 分组标题改为纯小节标签样式（`fg3` 12px、不可点、上方 `sp(6)`），条目保留；
  ② 若标题与唯一条目同名（扩展与关于→关于），合并为单条目。
- 底部状态条：「需重启生效 N 项」用 `wn` 色 chip（N=0 时整段隐藏）；「关闭」= secondary。
- 落点：`src/ui/settings/window.py`（导航树构建）+ 对应 cards。

### 5.7 帮助窗口（修 E13）

- **markdown 最简渲染**（P0 级可读性缺陷）：正文来自 commands 文档字符串的 markdown 子集，
  渲染层 `src/help_window.py` 至少支持 `**粗体**`（去星号+bold 字体）、行内 `` `code` `` 
  （Consolas + `logbg` 浅底）、`- ` 列表缩进三种标记；不支持的原样保留。
- **标题样式**：现用虚线下划线模拟 → 改「15px 加粗 + 底部 1px 实线（`bd` 色）」。
- **行内代码/选择器**（`.yidun_slider` 等）：等宽字体 + 浅底 chip，与日志面板 code 风格一致。
- **标题栏左上角图标残影**：低优先，检查 `iconphoto` 尺寸/透明通道。
- 底部快捷键提示条保留（已是正确样式）。

  `dark_btn(◐明暗)` + `settings_btn(⚙)` + `help_btn(?)` —— 低频导航类（设置/帮助）
  与高频状态型（置顶/明暗/折叠）混排，且纯图标不可发现。

### 9.2 目标布局

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 设置(S)   帮助(H)               ●就绪   △   ◐   ⊟           │
```

### 9.4 交互与样式

- **经典菜单栏风格**（2026-11-09 二次优化，参考传统 Windows menubar「文件(F) 编辑(E)…」）：
  入口 = 「设置(S)」「帮助(H)」**助记括号形态**（无 ▾ 箭头）；常态 `fgt` 文字，
  hover `surface_alt` 底 + `ac` 字；可 Tab 聚焦（复用 `bind_icon_activate`）。
- **Alt 助记直开**：`Alt+S` / `Alt+H` 直接弹出对应菜单（取代早先「不新增 Alt 助记键」的
  保守裁定）；可编辑控件（Entry/Text/Spinbox/Combobox）聚焦时**放行不劫持**；
  与全局热键（RegisterHotKey 体系）无冲突——热键为 Ctrl/组合键系，Alt+S/H 不在注册集内。
- **经典 menubar 交互**：① 一个菜单已弹出时，悬停另一入口**直接切换**；② 再点同一入口 = 关闭；
  ③ 菜单项右侧标注已知快捷键（`accelerator=`，如「命令速查 Ctrl+K」）。
- **弹出 Menu**：`tk.Menu(tearoff=0)` + 主题化
  （`bg=C["bgc"] / fg=C["fgt"] / activebackground=C["acl"] / activeforeground=C["fgt"] /
  bd=1, relief="solid"`）——实现按**当前色板现建现毁**（`ui_theme.colors(state.DARK_MODE)`），
  弹出即换肤、关闭即销毁，无换肤登记负担。
- 标题栏底部 1px 发丝线保留（§4.1）。
