# NetLink 网页面板「有限控制」使用说明（手机看进度 / 一键停止）

> 适用：NetLink Phase 4-2 演进（面板有限控制 + PWA）。
> 相关：[`netlink-网页只读面板说明.md`](netlink-网页只读面板说明.md)（接口与安全细节）、
> [`netlink-TLS加密说明.md`](netlink-TLS加密说明.md)（自签证书生成）。

本说明面向**本机所有者**：如何在手机上打开 ACRPA 网页面板、查看运行进度、
并在需要时**一键停止**或**运行当前脚本**。

---

## 0. 能力与边界（先读）

- ✅ **能看**：本机与已连接设备的运行状态、脚本、进度、循环、时长、定时、日志。
- ✅ **能控（需开启）**：**仅** `run`（运行当前已加载脚本）/ `stop`（停止当前运行）。
- ⛔ **不能**：`pause` / `resume`、推送脚本、远程截图、配对/权限变更。
- 🔒 控制动作受**三层门**约束：面板令牌（读）→ **强制 HTTPS** → **控制 PIN 解锁的短期会话**
  （外加 CSRF 头）。默认**全关**，不开控制时面板与旧版**完全一致（只读）**。

---

## 1. 开启步骤（只需做一次）

### 1.1 生成自签证书（控制强制 HTTPS）

控制要求 HTTPS，证书与设备互联**共用同一套**。用 `openssl` 生成（无需 CA/域名）：

```bash
openssl req -x509 -newkey rsa:2048 -nodes -days 3650 \
  -keyout key.pem -out cert.pem -subj "/CN=acrpa"
```

> 若机器无 `openssl`，可用 Git Bash / WSL。**本期不提供**证书自动生成。

### 1.2 在设置里配置证书并启用面板

1. 打开「设置 → 网络互联」；
2. 勾选 **启用浏览器只读监控面板**，填 **端口**（默认 `19712`），选 **监听范围**；
3. 在「证书PEM / 私钥PEM」两栏填入上面的 `cert.pem` / `key.pem`（或点 **浏览…**）；
4. 勾选 **面板启用 HTTPS（控制必需）**（开启控制时会自动强制）和
   **启用网页面板有限控制（run/stop，强制 HTTPS）**；
5. 需要时调整 **控制会话 TTL(秒)**（默认 `300`，范围 60–3600）；
6. 保存 → 面板会**自动重启**生效。

> **监听范围**：`所有网卡` 时，开启控制会**默认收窄为仅本机（127.0.0.1）**。
> 确需从手机（同网段）控制，请勾选 **允许局域网控制(高危)** 并确认风险提示；
> 同时用管理员 CMD 放行端口：
> ```cmd
> netsh advfirewall firewall add rule name="ACRPA NetLink WebUI" dir=in action=allow protocol=TCP localport=19712
> ```

### 1.3 设置控制 PIN（6 位）

打开「设备互联」窗口 → 底部 **[🌐 网页面板]** → 点 **[设置/重置控制 PIN]**：

- 输入 6 位数字并确定 → 设置成功；
- 直接留空确定 → 可选择**随机生成**（显示一次）或**清除**；
- 设置/重置后，**全部已解锁的控制会话立即失效**（需重新解锁）。

> PIN 存于 **Windows 凭据库**（`ACRPA/netlink/web-control-pin`），**不写 `config.json`**。
> 连续输错 5 次会**锁定**一段时间（`429`，指数退避），锁定期间正确 PIN 也被拒。

## 2. 在手机上使用

### 2.1 打开面板

1. 在电脑上打开「设备互联 → 🌐 网页面板」，点 **[复制地址]**（形如
   `https://192.168.1.5:19712/?token=xxxx`）；
2. 把链接发到手机（微信文件传输助手 / 邮件等），用**手机浏览器**打开；
3. 首次会提示证书「不安全」——选「继续访问/信任」（自签证书的正常现象）。

### 2.2 控制区（页面顶部，仅在控制开启时出现）

- **控制状态**：`控制：已锁定（需 PIN 解锁）` / `已解锁（剩余 mm:ss）` /
  `PIN 已锁定（重试 Ns）`；旁边显示 `HTTPS | 会话 TTL | 运行：运行中/空闲`。
- **解锁**：输入 6 位 PIN → 点 **[解锁]**（或键盘回车）。成功后剩余时间**每秒递减**，
  到期自动回到「已锁定」。
- **按钮状态**（禁用/启用自动联动）：
  - **[运行当前脚本]**：`已解锁` 且 `空闲` 且 `已加载脚本` 时可点；
  - **[停止]**：`已解锁` 且 `运行中` 时可点；
  - **[锁定]**：`已解锁` 时可点，点后立即失效会话。
- **结果提示**：控制区底部实时显示「运行完成 / 停止完成 / 被拒：原因」
  （如 `already running`、`no script selected`）。

### 2.3 安装到主屏（PWA，可选）

- 需通过 `https://` 访问（明文 + 局域网 IP 不支持安装）；
- Android Chrome / Edge：地址栏或页面出现 **[安装到主屏]** 按钮 → 点击安装；
- iOS Safari：点 **分享 → 添加到主屏幕**；
- 安装后从主屏打开 `/?src=pwa` **不含令牌**，会得到 401——用第 2.1 步的完整链接打开一次
  即可正常使用（安装能力与令牌鉴权相互独立）。

### 2.4 离线快照

- 页面每次成功刷新后把 `{时间, 概要, 设备, 定时}` 存进浏览器 `localStorage`
  （键 `acrpa.snap.v1`，**不含令牌、不含日志明细**）；
- 断网/面板停止时打开面板，会显示「⚠ 离线模式：显示最后快照（xx 分钟前）」+ **[重试]**；
- 恢复在线后自动回填最新数据。

## 3. 证书告警怎么处理

| 现象 | 说明 | 处理 |
| --- | --- | --- |
| 浏览器「您的连接不是私密连接」 | 自签证书未被系统信任 | 点「高级 → 继续访问」；或把 `cert.pem` 导入「受信任的根证书颁发机构」后重启浏览器 |
| 手机上同样告警 | 同上（手机需单独信任） | 同上；或使用系统信任的证书（自行签发/购买） |
| 面板启用失败，提示 `cert missing` / `key missing` | 证书或私钥路径为空 | 回到 1.2 步补齐两个 PEM 路径 |
| 提示 `cert load failed` | PEM 非法 / 证书与私钥不配对 / 私钥被口令加密 | 重新用 `-nodes` 生成；核对二者配对 |
| 手机能打开但显示「需通过 HTTPS」 | 用了 `http://` + 局域网 IP（非安全上下文） | 用 `https://` 链接，或本机 `http://localhost` |

> **注意**：自签证书虽然浏览器告警，**仍属 HTTPS 安全上下文**，
> Service Worker 与「添加到主屏」可用。

## 4. 常见问题

1. **看不到控制区** → 面板未开启「有限控制」（`/api/control/status` 返回
   `enabled:false` 时前端隐藏控制区）。回到 1.2 步开启。
2. **点了「解锁」没反应 / 提示 pin invalid** → PIN 错误；或已锁定（看状态行）。
   可在「🌐 网页面板 → 设置/重置控制 PIN」重置（重置即清会话）。
3. **「运行当前脚本」灰色** → 未解锁 / 正在运行 / 未加载脚本，三者之一。
4. **提示 `already running` / `no script selected`** → 状态不允许，属预期。
5. **动作很快又回到「已锁定」** → 控制会话 TTL 到期（默认 300s）；可在设置中调大
   `netlink_web_control_ttl`（最大 3600）。
6. **手机连不上** → 检查监听范围、防火墙入站规则、手机与电脑同网段，
   并使用电脑的**局域网 IP**。

## 5. 安全建议

- **令牌等同密码**：整条链接（含 `token=`）请勿外泄；定期 **[重新生成令牌]**。
- **仅可信内网**；无跨设备需求时把监听范围设为 `仅本机`。
- **控制默认收窄本机**；启用「允许局域网控制」前请确认网络可信。
- 忘记 PIN 用 GUI **重置/清除**（会清空全部控制会话）。
- 审计：`<config>/logs/netlink_audit_YYYYMMDD.log` 记录 `WEB_UNLOCK`、`WEB_PIN_FAIL`、
  `WEB_LOCK`、`WEB_REJECT`、`WEB_PIN_SET` 与 `CMD_RUN`/`CMD_STOP`（`actor=web-panel|<ip>`）。
