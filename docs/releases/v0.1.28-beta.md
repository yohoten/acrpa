# ACRPA v0.1.28-beta

## 本版更新

v0.1.28-beta (2026-10-01): **Beta 预发布** —— 新增 **NetLink 多设备互联**，并落地六项体验优化。本版为预发布版本，可能存在问题，建议先在测试机验证后再投入使用。

### NetLink 多设备互联

- 实时多机监控
- 零配置 UDP 发现（含静态对端兜底）
- PIN 配对 + `PBKDF2` / `nonce` 挑战应答 + 三档权限（仅观察 / 允许操控 / 允许接收脚本）
- 远程运行 / 暂停 / 恢复 / 停止（脚本与工作流自动分叉）
- 远程截图
- 脚本分发（64KB 分块 + sha256 校验 + 批量下发）
- 浏览器只读面板（令牌鉴权）
- TLS 可选加密（自签 + TOFU 指纹固定）
- 审计日志

### 六项体验优化

1. Mini Bar 三形态 / 高度可配 / 位置记忆 / 状态点（并修复「系统卡设置不生效」D-1 / D-2）
2. 暗黑模式修复（`themed()` 护栏 + Toast 主题化 + 19 处 `insertbackground`）
3. 互联按钮瘦身（`🌐`）
4. 自定义 AI 提供商 / 模型 / BaseURL（密钥入 Windows 凭据库 D-3）
5. Python 代码扩展（`py_sandbox` 沙箱 + AST 预检 + 三层超时 + 审计 + `AcrpaAPI`）
6. 字体与显示缩放（命名字体 + `ui_scale` 7 档 + DPI 感知，60 处硬编码字体统一）

### 已知限制

- 真机跨机验收未执行。
- TLS 真实握手未在开发机验证（缺 `cryptography` / `openssl`）。
- 浏览器只读面板为明文 HTTP + 令牌。
- UDP 广播发现在 VLAN / 多网卡环境不可靠，需静态对端兜底。
- Python 脚本级钩子仅在单脚本场景生效（工作流不触发）。
- `python_full_enabled` 与 `netlink_tls` 默认关闭。
