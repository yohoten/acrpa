# ACRPA v0.1.30-beta

> 发布 tag：**`v0.1.30-beta`**（Pre-release / 预发布） · 发布日期：**2026-11-06** · 平台：**Windows x64** · 许可证：**MIT**

## 本版更新

本次为**工作流执行语义、工作流编辑体验、可观测性与 AI 能力**的集中增强：工作流新增 `retry` 重试 / `rollback` 失败补偿 / `workflow` 子工作流引用 / `parallel` 真并行四类执行语义，补齐**版本历史 / 撤销重做**，并把失败现场从「只落盘」升级为「只读查看 + 两次运行对比」；AI 生成接入**流式输出 + token 记账 + 结果缓存**，支持**自然语言生成工作流图**。全链路新增统一 **`run_id`** 关联日志、历史与失败现场。脚本列结构未变，旧脚本 / 旧工作流 / 旧 Excel 文件无需修改。

### 一、工作流执行语义

- **`retry` 失败重试**：新增独立步骤类型，失败按 `delay` 退避重试，超过 `max_attempts` 抛出最后一次异常。
- **`rollback` 失败补偿**：任一步骤支持 `on_error_rollback` 子步骤列表，失败时先执行补偿步骤再向上抛错，使外层 `STOP_ON_ERROR` 语义成立。
- **`workflow` 子工作流引用**：加载另一工作流文件，`inputs` 写入局部作用域、`outputs` 回写父作用域；内置循环引用检测与嵌套深度上限，越界路径被拒绝。
- **`parallel` 真并行**：每个分支拥有独立变量作用域、互不可见，仅声明为 `outputs` 的变量按分支定义顺序确定性合并回主作用域；分支失败按 `STOP_ON_ERROR` 汇总抛出。

### 二、工作流编辑体验

- **版本历史**：工作流保存后自动存档快照，支持查看 / 恢复 / 差异对比，与脚本编辑器的版本历史对齐。
- **撤销 / 重做**：快照栈（上限 100）+ `Ctrl+Z` / `Ctrl+Shift+Z` / 工具栏按钮，覆盖新增、编辑、删除、移动、复制、粘贴、清空、导入、打开。

### 三、可观测性

- **统一 `run_id`**：一次运行生成唯一标识，贯穿文件日志、`history.jsonl`、`fail_context_*.json` 与 CLI JSON 报告四条通道；旧记录无 `run_id` 仍可正常读取。
- **失败现场只读查看**：只读面板展示失败时的变量（脱敏）、截图、行号、命令、attempts 与上下文；支持选取两条记录做**两次运行对比**（变量并集 diff + 截图并排 + 元信息），不重跑、无副作用。

### 四、AI 深化

- **流式输出**：SSE 逐段回显正文，避免长文本卡界面；流式异常 / 空正文自动降级为非流式路径。
- **token 记账 / 结果缓存 / 失败退避**：按模型累计用量（仅存数量 / 模型 / 时间，脱敏）；命中缓存直接返回；`429` / 超时走指数退避 + 抖动。
- **自然语言 → 工作流图**：用自然语言描述流程生成工作流 JSON，经 `flow_graph.analyze` 静态检查兜底后载入编辑器。
- **工作流「AI 生成」复用脚本侧对话式面板**：脚本 / 工作流共用同一套流式展示、API Key 检查、模型选择、建议提示词与错误处理，体验一致。

### 五、修复

- 修复工作流「AI 生成」按钮点击即崩（未导入 `utils` 导致的 `NameError`）。
- 修复 AI 对话面板关闭后，残留全局鼠标滚轮绑定触发 `invalid command name` 崩溃。
- 修复 `热键` 命令多键组合解析丢键、参数不足静默成功等历史问题（上一版已合入，本版保留）。

### 兼容性说明

- 脚本列结构未变；旧工作流 JSON、旧 `history` / `fail_context`（无 `run_id`）仍可正常读取运行。
- 新步骤类型不影响旧工作流解析；`flow_graph` 遇未知类型降级为安全通过而非崩溃。
- 无新增第三方依赖（AI 流式仍基于 `requests` 手写 SSE 解析）。

### 已知限制

- 本轮不做 function-calling 工具闭环（生成 → 校验 → 干跑 → 自动修正延后）。
- 失败现场为只读查看 + 两次运行对比，不做一键重跑。
- 真机跨机验收未执行；构建产物由 `build.py` 本地生成，**未做代码签名**（首次运行如出现 SmartScreen 提示，选择「更多信息 → 仍要运行」）。

- **便携版**：双击运行 `ACRPA-v0.1.30-beta.exe`（无需安装，程序内自报版本为 `0.1.30-beta`）。
