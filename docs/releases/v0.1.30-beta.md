# ACRPA v0.1.30-beta

> 发布 tag：**`v0.1.30-beta`**（Pre-release / 预发布） · 发布日期：**2026-10-31** · 平台：**Windows x64** · 许可证：**MIT**

## 本版更新

本次为脚本编辑能力的聚焦增强：脚本编辑区的 **`热键` 命令由「只支持 2 个按键」扩展为「支持 2~4 个按键」**，并同步录制器、扩展 API、AI 生成提示词与脚本编辑模板；同时修掉了几处历史遗留的**静默失败**与**组合键解析丢键**问题。脚本列结构未变，旧脚本与旧 Excel 文件无需修改。

### 一、`热键` 命令支持 2~4 个按键

- 参数由 2 个扩展为 4 个：`按键1, 按键2, 按键3(可选), 按键4(可选)`，可按顺序配置多键组合，例如 `热键,ctrl,shift,alt,a`（Ctrl+Shift+Alt+A）。
- 参数3、参数4 为**可选**：不填时行为与旧版完全一致，仍按序依次按下、按逆序释放。
- 命令说明与参数提示同步为「组合键操作(2~4个按键)」，脚本编辑区下拉提示与帮助窗口保持一致。
- 脚本编辑模板 `res/template/ACRPA脚本编辑模板.xlsx` 随本版重新生成，内含新参数格式与示例。

### 二、录制器支持多修饰键组合

- 「录制」现在支持**多个修饰键**的组合：依次按下 Ctrl → Shift → Alt → A，会录制出 `热键,ctrl,shift,alt,A`，修饰键按**首次按下顺序**记录。
- 键盘钩子与轮询两条录制路径均已同步支持；LShift / RShift 这类同名键在另一只仍按住时不会被误清空。
- 录制输出统一为 9 参数格式：修饰键占参数1..N，主键紧随其后，其余留空（不再把 `1` / `0.1` 写进参数3/4，避免与多键语义冲突）。

### 三、扩展 API 与 AI 生成提示词

- 扩展 API `key_press()` 支持**任意段数**的组合键字符串（如 `"ctrl+shift+alt+a"`）；超过 4 段自动截断并记一条 warning，少于 2 段直接返回失败。
- AI 生成脚本的提示词已同步新参数格式，并补充三键组合示例，可直接生成 3~4 键组合。

### 四、修复

- **参数不足不再静默成功**：`热键` 命令有效按键少于 2 个时（例如只填了 `按键1`），以前会被静默当作执行成功；现在会在**执行前校验并报错**，日志明确提示「至少需要 2 个非空按键参数」。
- **旧录制格式保持兼容**：旧版录制器生成的 `热键,ctrl,s,1,0.1` 历史脚本 / Excel 文件会被自动识别，只使用前两个按键并记一条 warning 说明；`.xls` 数值单元格被转成 `1.0` / `0.1` 的情况同样能识别。
- **修复 `key_press("ctrl++")` 解析丢键**：组合键末尾的 `+` 现在被视为「加号键」本身，正确解析为 `Ctrl + 加号`，不再丢键。

### 兼容性说明

- 脚本列结构未变，仍是 **9 个位置参数**，旧脚本与旧 Excel 文件无需任何修改。
- 参数3、参数4 留空时行为与 v0.1.29 完全一致，无行为变更风险。
- 无新增第三方依赖。

### 已知限制

- 大写字母组合键（如 `热键,ctrl,shift,A`）在部分键盘布局下的真实按键注入效果**待实机验证**；若个别键位不生效，可改用小写键名对比定位。
- 旧录制格式识别依赖「参数3 为 `1` 且参数4 为 `0.1`」这一特征，若历史脚本恰好是该两值的三键组合，会按旧格式仅取前两键（可手动把参数3/4 改为空以规避）。
- 真机跨机验收未执行；本版为**源码预发布**，构建产物由 `build.py` 本地生成，**未做代码签名**（首次运行如出现 SmartScreen 提示，选择「更多信息 → 仍要运行」即可）。

## 安装

双击运行 `ACRPA-v0.1.30-beta.exe`（便携版，无需安装，程序内自报版本为 `0.1.30-beta`）。

已装旧版的用户：启动后状态栏会提示新版本，点击即可在应用内下载并重启更新，**配置、脚本、模板、日志均不受影响**。
