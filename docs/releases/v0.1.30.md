# ACRPA v0.1.30

> 发布 tag：**`v0.1.30`**（正式版 / Stable） · 发布日期：**2026-11-09** · 平台：**Windows x64** · 许可证：**MIT**

## 本版更新

本次为 **v0.1.30 正式版**：由本版源码重新构建（去除 `-beta` 预发布标识，程序内自报版本同步为 `0.1.30`）。在 v0.1.30-beta 的功能基线（工作流 `retry`/`rollback`/`workflow`/`parallel` 四类执行语义、版本历史与撤销重做、统一 `run_id`、失败现场对比、AI 流式生成）之上，完成 **UI 视觉规范 v6 落地**、**主窗布局与交互重构**、**AI 调试面板统一**，并把安装包纳入 `build.py` 一键构建。脚本列结构未变，旧脚本 / 旧工作流 / 旧 Excel 文件无需修改。

### 一、UI 视觉规范 v6 落地（本次重点）

- **页签（Tab）**：重写 `Notebook.tab` 布局，去除 clam 主题自带焦点虚线框；选中态改为 `surface_alt` 底 + **底部 2px 强调色条** + 文字加粗，未选中为透明底弱化字；色条用一次性图片元素实现，**无逐帧绘制开销**，随主题切换重建。
- **工具栏分组**：组间统一 1px 发丝竖线（上下各留 4px）；脚本编辑工具条**文件组前置**（新建 / 打开 / 保存 / 另存 / 版本），编辑组、AI 组、工具组、录制组依次排列，**危险组（删除 / 清空）恒排最右**；工作流工具条把「导出模板」归入文件组、「清空」移至最右危险组。
- **操作库树（工作流）**：命令条目按语义类别区分图标（区域 ▭ / 找图·找色·截屏 ▣ / 键鼠 ⌨ / 文本 ¶ / 控制流 ⟳，未命中回退分组图标）；悬停说明首行恒为**命令全名**（侧栏窄、长条目被截断时仍可读全名）；搜索无结果时显示空态浮层。
- **空态体系统一**：设备表、定时任务表、操作库搜索新增「图标 + 主句 + 副句 + 主按钮」空态（如「还没有已配对设备 → [显示配对码]」「暂无计划任务 → [新建任务]」）；编辑区空态快捷键渲染为**键帽样式**（强调色描边小色块）。
- **设备互联**：设备日志 `Text` 外框接主题（原系统默认粗黑框改为 `bd` 1px，聚焦态强调色），换肤后边框跟随；设备表空表不再是一屏空白表头。
- **定时任务**：「下次执行 `--:--`」无计划时改用占位灰（有计划才用强调色），空信息不再抢眼。
- **设置窗口**：左导航分组标题降为纯小节标签（弱化色 + 上方留白、不可点），消除「基础设置 → 常规」「扩展与关于 → 关于」的层级重名；「需重启生效 N 项」改为警示色描边 chip，N=0 时整段隐藏。
- **帮助窗口**：正文支持 Markdown 行内渲染——`**粗体**` 去掉字面星号并按粗体显示、`` `代码` `` 使用等宽字体 + 浅底 chip、列表项内的行内样式同样生效（修复正文出现字面 `**` 的可读性缺陷）；章节标题下划线改为 **1px 实线**（原为字符虚线的廉价观感）。
- **性能约束**：本轮新增/改造控件全部为静态控件，未引入任何 `after` 轮询、动画或逐帧重绘；空态显隐为幂等单次调用，搜索沿用「签名不变即跳过重建」的既有优化。

### 二、AI 体验

- **工作流「AI生成」配色对齐**：改为与脚本编辑同款紫色（`ai` 语义角色紫底 + 自适应字色），hover / 描边 / 换肤行为完全一致；文案统一为 `AI生成`。
- **工作流新增「AI调试」**：紧邻 AI生成，同一紫色规格；复用脚本编辑同款调试面板，以工作流语境打开，并把当前**工作流步骤摘要**作为上下文提交给 AI（新增 `workflow_steps` 上下文通道，脚本调试路径行为不变）。
- **AI 调试面板重构（脚本 / 工作流共用）**：参考「AI 生成」面板统一视觉——
  - 顶部状态卡：标题 + 副标题 + API 状态点与当前模型（可点击跳转设置，带悬停提示）；
  - 建议问题 chip：两列布局、描边 + 强调色文字 + hover 底色；工作流模式换成节点执行 / 耗时 / 分支类问题；
  - 输入卡：多行输入 + 灰字占位 + 右置「发送」主按钮，`Enter` 发送 / `Shift+Enter` 换行 / `Ctrl+Enter` 发送；
  - 回答卡：「AI 回答 · 只读可复制」卡片头 + 只读正文 + 滚动条，空闲时显示占位说明；
  - 状态 / 进度：状态行带 `⧗ / ✔ / ✘` 前缀，进度条仅在分析中显示并动画，静止时无动画开销；
  - 底部操作条：「复制回答」「关闭」均为次级描边按钮，不再使用红色实心关闭。

### 三、主窗布局与交互重构

- 主窗布局与交互统一：执行栏、日志面板、标题栏、命令面板、窗口骨架等按 UI 视觉规范收敛（相关模块：`exec_bar` / `log_dock` / `window_shell` / `command_palette` / `param_form` / `rounded_button`）。
- **新增「定时任务」Tab**：在主窗「工作流」之后新增独立 Tab（左侧「管理计划任务」嵌入为主页面，右侧为窄设置面板）；设置窗口中的定时任务内容随之迁移，托盘「打开定时执行设置」改为直接聚焦并切换到该 Tab。
- 工作流编辑体验补坑与主页面（`index.html` / `index.en.html`）同步更新到本版口径。

### 四、构建与发布

- `build.py` 新增 **`--inno`**：一次构建产出**便携版单文件 EXE + 文件夹版 + Inno Setup 安装包**（`ACRPA-vX.Y.Z-setup.exe`，含开始菜单 / 桌面快捷方式，默认安装到用户目录、无需管理员权限）。
- 体积门禁保留：主程序超限即失败（本版 18.02 MiB，上限 300 MiB）。
- `lib/paddle_ocr` 原生依赖不全时**跳过打包**并明确提示（缺 `paddle_inference.dll` / `tbb12.dll` / `yaml-cpp.dll` / `opencv_world470.dll`），不影响其余功能构建。
- 发布助手 `tools/publish_release.py` 支持**多附件**上传（便携版 + 安装包），并在附件名与 `VERSION` 直链末段不一致时直接失败，避免上线即 404。

### 兼容性说明

- 脚本列结构未变；旧脚本、旧工作流 JSON、旧 `history` / `fail_context`（无 `run_id`）均可正常读取运行。
- 本轮 UI 改造为**渲染层改动**，未修改任何按钮回调、快捷键行为与配置文件格式。
- 沿用 v0.1.30-beta 的全部执行语义新增项，对旧工作流向后兼容（未知步骤类型降级为安全通过）。
- 无新增第三方依赖。

### 已知限制

- 本轮未落地 v6 方案中「按钮语义角色重排」（约 50 个按钮的 primary/secondary/ghost 降级），留待后续版本；现有按钮配色保持不变。
- 失败现场为只读查看 + 两次运行对比，不做一键重跑；AI 调试为「提问 → 分析」单轮问答，不做多轮工具闭环。
- `lib/paddle_ocr` 未随包分发（本仓库缺 4 个原生依赖），PaddleOCR.dll 后端需自备依赖与模型，默认关闭。
- 构建产物由 `build.py` 本地生成，**未做代码签名**（首次运行如出现 SmartScreen 提示，选择「更多信息 → 仍要运行」）。
- 真机跨机验收未执行；NetLink TLS 真实握手未在开发机验证。

## 安装

- **便携版**：双击运行 `ACRPA-v0.1.30.exe`（无需安装，程序内自报版本为 `0.1.30`，窗口标题显示版本号）。
- **便携压缩包**：解压 `ACRPA-v0.1.30-portable.zip` 后运行其中的 `ACRPA v0.1.30.exe`。
- **安装包**：运行 `ACRPA-v0.1.30-setup.exe`，按向导完成安装（默认安装到用户目录，无需管理员权限）。

已装旧版的用户：启动后状态栏会提示新版本，点击即可在应用内下载并重启更新，**配置、脚本、模板、日志均不受影响**。
