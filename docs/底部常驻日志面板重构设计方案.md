## 2. 目标架构：两 Tab + 常驻执行控制栏 + 常驻日志面板

### 2.1 root 网格骨架

```text
root (grid, column0 weight=1)
├─ row0  weight=0   ① 标题栏            title_bar
├─ row1  weight=0   ② 执行控制工具栏     exec_bar   ← 原 tab_exec 的 card_run 精简升级，常驻
├─ row2  weight=1   ③ main_paned = PanedWindow(orient="vertical")
│                     ├─ pane#0 : notebook（脚本编辑 | 工作流）
│                     └─ pane#1 : bottom_dock（底部日志面板，默认160/min60/可拖/可收起）
└─ row3  weight=0   ⑦ 状态栏            status_bar
```

> **为何是 PanedWindow 而非 grid 直连**：tkinter `grid` 没有可拖 sash，「可拖 + minsize + 一键收起」的原生正解只有 `PanedWindow`。因此需求里「内容与日志之间加一行」收敛为：row2 由 `main_paned` 纵向切出「内容 pane + 日志 pane」。

### 2.2 与现有代码的对应

```python
# ① 标题栏：不动位置（只重排/补充右簇图标）
title_bar.grid(row=0, column=0, sticky="ew")

# ② 执行控制工具栏：新增常驻行（内容 = 原 card_run 精简）
exec_bar = tkinter.Frame(root, bg=C["bg"])
exec_bar.grid(row=1, column=0, sticky="ew", padx=8, pady=(0, 2))

# ③ main_paned：内容 + 日志
main_paned = tkinter.PanedWindow(root, orient="vertical",
    bg=C["bd"], sashwidth=4, sashrelief="raised", opaqueresize=True, bd=0)
main_paned.grid(row=2, column=0, sticky="nsew", padx=8, pady=(0, 3))
main_paned.add(notebook,   minsize=200, stretch="always")          # pane#0 内容
main_paned.add(bottom_dock, minsize=60, height=160, stretch="never")  # pane#1 日志

# ⑦ 状态栏：不动位置
status_bar.grid(row=3, column=0, sticky="ew")
```

> `notebook` 不再 `grid(row=1)`，改为 `main_paned.add(...)`；其余控件树保持不变。
> 被删除的 Tab：`tab_exec`（其 `card_run` 内容 → `exec_bar`；其 `card_log` → `bottom_dock`）。

## 11. 结论

1. **`tab_exec` 拆解**：`card_run` → ② 常驻执行控制工具栏；`card_log` → ⑥ 底部常驻日志面板。这正是「两 tab 共用 + 移除工作流运行停止 + 执行控制瘦身」的统一落法。
2. **日志是「提升 + 换父」**：运行链路 `rz`/`_tlog`/`_log_*`/`_periodic` **零改动**。
3. **`PanedWindow(orient="vertical")`** 是「可拖 + minsize + 一键收起」的原生正解。
4. 按 **P0 → P1 → P2** 落地，P0 即可独立验收并解决 P4。
