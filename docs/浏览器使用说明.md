# ACRPA 浏览器自动化使用说明

> 面向脚本编写者的用户手册：定位 DSL 语法、命令清单、`${变量}` 与结果写回、Cookie 用法、常见失败短语与排查。
> 实现位于 [`src/browser_backend.py`](src/browser_backend.py)，设计稿见 [`docs/浏览器后端增强设计.md`](docs/浏览器后端增强设计.md)。
> 本模块为**净室重写**：仅借鉴公开的 DSL 前缀约定与「状态枚举 + 轮询 + 超时」通用工程思路，算法与实现均为独立完成，
> 不含任何第三方库源码片段。

---

## 1. 安装与启用（可选依赖）

浏览器后端基于 **Playwright (Chromium)**，属**可选**安装，不随 ACRPA 分发：

```cmd
pip install playwright
playwright install chromium
```

- 未安装时，所有浏览器命令都会**静默降级**：写入 `browser_last_error = PW_NOT_INSTALLED`，不影响脚本其它步骤。
- `import browser_backend` **不会**触发 playwright 导入（懒加载），未安装也能正常加载引擎。
- 体积：Python 包约 5 MB，Chromium 约 150 MB，合计约 155 MB。

| 浏览器点击 | `<选择器>` | 按定位 DSL / CSS / `text=` 点击（内部重试 `browser_retry` 次） | 成功 `None` | `ELEMENT_NOT_FOUND` / `INVALID_LOCATOR` / `INVALID_ARGUMENT` / `PW_NOT_INSTALLED` |

| 浏览器读取Cookie | ★`<目标变量名=cookie>`, ★`<格式:json/header/netscape=json>`, ★`<保存路径>` | 导出上下文 Cookie 到变量（可选同时落盘，UTF-8） | 写回 `<目标变量名>`；成功 `None` | `COOKIE_ERROR` / `PW_NOT_INSTALLED` |
| 浏览器设置Cookie | `<来源:变量名/文件路径/字面量>`, ★`<域名>` | 解析来源并注入上下文 | 成功 `None` | `COOKIE_ERROR` / `INVALID_ARGUMENT` / `PW_NOT_INSTALLED` |
| 切换框架 | `<定位表达式>` / `<索引>` / `main` | 进入 iframe（DSL 定位 / 第 N 个 frame）或回主文档（`main`/`主文档`/`顶层`/`top`） | 成功 `None` | `FRAME_NOT_FOUND` / `INVALID_ARGUMENT` / `PW_NOT_INSTALLED` |
| 返回主框架 | 无 | 等价 `切换框架, main` | 成功 `None` | `FRAME_NOT_FOUND` / `PW_NOT_INSTALLED` |
| 新建标签页 | ★`<网址>` | 新建标签页（可带 URL，支持 `${变量}`）并切换为活动页 | 成功 `None`；刷新 `browser_url`/`browser_title` | `TAB_FAILED` / `NAV_FAILED` / `PW_NOT_INSTALLED` |
| 切换标签页 | `<序号>` / `<标题>` / `<URL>` | 按序号（0 基）/ 标题包含 / URL 包含切换活动页 | 成功 `None`；刷新 `browser_url`/`browser_title` | `TAB_NOT_FOUND` / `INVALID_ARGUMENT` / `PW_NOT_INSTALLED` |
| 关闭标签页 | ★`<序号=当前>` | 关闭当前或指定标签页；关活动页则回退到最后一个剩余页 | 成功 `None` | `TAB_NOT_FOUND` / `TAB_CLOSE_FAILED` / `PW_NOT_INSTALLED` |
| 等待下载 | ★`<保存目录>`, ★`<文件名匹配>`, ★`<超时秒数=15>`, ★`<写回变量名>` | 等待下载完成并落盘（`/正则/` 匹配文件名） | 绝对路径写回变量（缺省 `浏览器下载路径`） | `DOWNLOAD_TIMEOUT` / `DOWNLOAD_ERROR` / `PW_NOT_INSTALLED` |
| 浏览器上传 | `<定位表达式>`, `<文件路径1>`, ★`<文件路径2..N>`, ★`<是否清空=是>` | 对 `input[type=file]` 设置本地文件（路径支持 `${变量}`） | 成功 `None` | `UPLOAD_ERROR` / `ELEMENT_NOT_FOUND` / `INVALID_LOCATOR` / `INVALID_ARGUMENT` / `PW_NOT_INSTALLED` |
| 连接已开浏览器（别名 接管浏览器） | ★`<endpoint=配置>`, ★`<是否关闭旧会话=是>` | 通过 CDP 接管已开 Chrome/Edge | 成功 `None`；刷新 `browser_url`/`browser_title` | `CDP_CONNECT_FAILED` / `INVALID_ARGUMENT` / `PW_NOT_INSTALLED` |
| 开始监听 | ★`<URL匹配>`, ★`<资源类型>`, ★`<队列上限=配置>` | 对当前页注册响应监听，命中过滤后入队 | 成功 `None` | `LISTEN_ERROR` / `PW_NOT_INSTALLED` |
| 等待数据包 | ★`<URL匹配>`, ★`<数量=1>`, ★`<超时秒数=配置>`, ★`<写回变量名>`, ★`<导出路径>`, ★`<导出格式=json>` | 等待并取回命中的数据包（去重键 = `method+url+status`） | JSON 列表写回变量；给定路径则落盘 | `TIMEOUT` / `INVALID_ARGUMENT` / `LISTEN_ERROR` / `PW_NOT_INSTALLED` |
| 停止监听 | 无 | 停止监听并清空队列（幂等） | 成功 `None` | — |
| 启动浏览器录制 | 无 | 调用 playwright codegen 并把结果转为 DSL 追加到录制 | 成功 `None` | `RECORD_ERROR` |

**Excel 示例**

```text
打开网页, https://example.com/login
等待元素, text:用户名, 15, 可见
浏览器输入, #username, ${login_user}
浏览器点击, role:button[name=登录]
浏览器执行JS, () => document.querySelectorAll('a').length, link_count, 否
浏览器截图, dashboard, 整页, , shot_path
浏览器读取Cookie, cookie_json, json, D:\out\cookies.json
```

命令与 handler 的绑定见 [`src/engine.py`](src/engine.py)；注册表见 [`src/commands.py`](src/commands.py)。

## 3. 浏览器截图：视口 / 整页 / 元素

| 目标参数 | 行为 |
| --- | --- |
| 缺省 / `page` / `视口` / `viewport` / 空 | 视口截图（是否整页取决于配置 `browser_full_page_screenshot`，默认 `False`） |
| `整页` / `full` / `fullpage` / `full_page` | 整页截图（`full_page=True`） |
| 其它任意串 | 按**定位 DSL** 解析为元素并对其截图 |

- **保存路径**：给定第 3 参数则保存到该路径（父目录自动创建，支持 `${变量}`）；缺省保存到 `screenshots/` 目录，文件名为 `browser_<名称>_<时间戳>.png`。
- **写回变量**：第 4 参数为写回变量名；缺省写回 `浏览器截图路径`。

## 4. 等待元素：状态表

第 3 参数（状态）支持中文 / 英文 / 同义词，缺省为「出现」：

| 参数值 | 归一化 | 实现要点 |
| --- | --- | --- |
| 出现 / 可见 / 显示 / visible | `visible` | Playwright 原生 `wait_for(state="visible")` |
| 消失 / 隐藏 / hidden | `hidden` | `state="hidden"` |
| 存在 / 附加 / attached | `attached` | `state="attached"` |
| 移除 / 删除 / detached | `detached` | `state="detached"` |
| 可点击 / clickable | `clickable` | 轮询：可见 + 可用 + 位置稳定 |
| 可用 / enabled | `enabled` | 轮询 `is_enabled()` |
| url变动 / 网址变动 / url | `url` | 轮询 `page.url != 期望值`（期望值取第 4 参数） |
| 标题变动 / 标题 / title | `title` | 轮询 `page.title() != 期望值` |
| 下载开始 / download | `download` | 暂未实现，统一返回 `INVALID_ARGUMENT`；下载请用 `等待下载` 命令 |
| 导航 / navigation | `navigation` | 暂未实现，统一返回 `INVALID_ARGUMENT` |

> 向后兼容：第 3 参数缺省 = `出现`（visible）；`消失` → hidden。旧脚本 `等待元素, .result, 10, 出现` 完全等价。
> 未知状态会按「出现」处理并写 `INVALID_ARGUMENT` 到 `browser_last_error`。

## 5. 定位 DSL 语法表

解析顺序（保序）：

1. 空 / 纯空白 → `INVALID_LOCATOR`；
2. `@@` 组合优先；
3. 自定义 DSL 前缀（`css:` / `xpath:` / `text:` / `text^` / `text$` / `tag:` / `@` / `role:` / `label:` / `placeholder:` / `testid:`）；
4. 原生前缀或「形似 CSS」→ 原样直通；
5. 其余 → 默认**模糊文本**匹配。

| DSL 前缀 | 语义 | 示例 | 映射到 Playwright |
| --- | --- | --- | --- |
| 无前缀（非 CSS） | 默认模糊文本（包含匹配） | `登录按钮` | `get_by_text("登录按钮", exact=False)` |
| `css:` | 强制 CSS | `css:#id > .cls` | `locator("#id > .cls")` |
| `xpath:` | XPath | `xpath://button[text()="登录"]` | `locator("xpath=//button[text()=\"登录\"]")` |
| `text=` | 文本精确（原生直通，兼容旧脚本） | `text=登录` | `locator("text=登录")` |
| `text:` | 文本包含（模糊） | `text:登录` | `get_by_text("登录", exact=False)` |
| `text^` | 文本开头匹配 | `text^登 录` | `get_by_text(re.compile("^登\\ 录"))` |
| `text$` | 文本结尾匹配 | `text$完成` | `get_by_text(re.compile("完成$"))` |
| `tag:` | 标签名（可叠加属性） | `tag:button` | `locator("button")` |
| `tag:x@a=v` | 标签 + 属性等值 | `tag:input@type=submit` | `locator("input[type=submit]")` |
| `@attr` | 属性存在 | `@data-id` | `locator("[data-id]")` |
| `@attr=val` | 属性等值 | `@name=user` | `locator("[name=user]")` |
| `@@` 组合 | 多条件 AND | `tag:button@@text:提交` | `locator("button").filter(has_text="提交")` |
| `role:` | ARIA role（可带 `name`） | `role:button[name=登录]` | `get_by_role("button", name="登录")` |
| `label:` | 表单 label | `label:用户名` | `get_by_label("用户名")` |
| `placeholder:` | 占位符 | `placeholder:请输入手机号` | `get_by_placeholder("请输入手机号")` |
| `testid:` | `data-testid` | `testid:submit-btn` | `get_by_test_id("submit-btn")` |

原生直通（行为不变）：`text=` / `xpath=` / `css=` / `role=`，或形似 CSS 的串（以 `#` `.` `[` `*` `>` 开头，或包含 `# . [ ] > : * ,` 与空格，或纯标签名如 `button`）。

> 说明：`@@` 组合中 `text^` / `text$` 片段暂不支持；`@@` 的属性 / `text` 追加片段仅对 CSS / `tag:` 基串生效。
> 定位表达式无效时统一写 `browser_last_error = INVALID_LOCATOR`。

### 5.1 链式组合与相对定位（P1）

在既有 DSL 之上**只新增**「链式收窄」能力，不改变任何既有前缀语义：

- 组合算子 `>>`：左侧解析为基础定位，右侧为**步骤**逐级收窄（左 → 右）。例：`#table >> tag:tr >> nth:1`。
- 求值优先级：`@@` **高于** `>>`（`A@@B>>C` ≡ `(A@@B)>>C`）。
- 步骤算子**必须**出现在 `>>` 右侧；单独出现（无基串）→ `INVALID_LOCATOR`。

| 步骤算子 | 语义 | 示例 | 映射到 Playwright |
| --- | --- | --- | --- |
| `nth:N` / `index:N` | 取第 N 个（0 基，负数=从末尾） | `tag:li >> nth:2` | `.nth(2)` |
| `first:` / `last:` | 取首个 / 末个（等价 `nth:0` / `nth:-1`） | `tag:li >> last:` | `.nth(-1)` |
| `parent:` | 上一级父元素 | `#child >> parent:` | `.locator("xpath=..")` |
| `child:SPEC` | 子代 / 后代定位 | `#form >> child:input` | `.locator("input")` |
| `next:` / `prev:` | 相邻后 / 前一个兄弟 | `#a >> next:` | `.locator("xpath=following-sibling::*[1]")` |
| `filter:文本` | 同层按文本过滤 | `tag:li >> filter:完成` | `.filter(has_text="完成")` |
| `has:SPEC` | 同层要求包含某后代 | `tag:div >> has:tag:a` | `.filter(has=<locator>)` |

> 兼容性：单个 `>` 仍是 CSS 直通（`#a > div` 行为不变）；只有显式出现 `>>` 才按链式解析。
> 非法 `>>` 形态（如 `#a >> `、`>> div`、`#a >> nth:x`）统一写 `browser_last_error = INVALID_LOCATOR`。

## 6. `${变量}` 与结果写回

浏览器命令在 [`browser_backend.py`](src/browser_backend.py) 内自行解析 `${变量}`，并把结果写回 [`engine.variables`](src/engine.py)（供后续 `如果` / `数学运算` 等命令引用）。

**支持 `${变量}` 的浏览器命令参数**：

- `打开网页`：网址
- `浏览器输入`：文本
- `浏览器截图`：保存路径
- `浏览器读取Cookie`：保存路径
- `浏览器设置Cookie`：来源（另含 `_resolve_vars`）
- `新建标签页`（P1）：网址
- `浏览器上传`（P1）：各文件路径
- `等待数据包`（P2）：导出路径

> 注意：`浏览器点击` 的选择器、`浏览器执行JS` 的脚本**不做** `${变量}` 替换，请直接书写字面量。

**写回的变量**：

| 变量 | 含义 | 写入时机 |
| --- | --- | --- |
| `browser_url` / `browser_title` | 当前 URL / 标题 | `打开网页` |
| `browser_last_error` | **稳定失败短语（code）** | 任意命令失败时；成功清空为 `""` |
| `browser_last_message` | 人类可读失败描述 | 同上 |
| `<目标变量名>` | 命令结果（`浏览器执行JS` 返回值为 dict/list/number/str 原样写回） | `浏览器执行JS` / `浏览器读取Cookie` |
| `浏览器截图路径` | 截图文件路径 | `浏览器截图`（未指定写回变量名时的默认变量名） |
| `浏览器下载路径` | 下载文件绝对路径 | `等待下载`（未指定写回变量名时的默认变量名） |

> `新建标签页` / `切换标签页` / `关闭标签页` / `连接已开浏览器` 成功后同样刷新 `browser_url` / `browser_title`。

脚本可用条件判断稳定识别失败原因（配合既有 `如果` 命令）：

```text
如果, ${browser_last_error} == ELEMENT_NOT_FOUND
```

## 7. Cookie 用法

**读取（浏览器读取Cookie）**

```text
浏览器读取Cookie, cookie_json, json                       # JSON 写回变量
浏览器读取Cookie, cookie_header, header, D:\out\hdr.txt   # header 串 + 落盘
浏览器读取Cookie, cookie_ns, netscape                     # Netscape 格式
```

- 格式：`json`（默认，返回 Cookie 对象数组）/ `header`（`k=v; k2=v2`）/ `netscape`（Netscape Cookie File 文本）。

**设置（浏览器设置Cookie）**

```text
浏览器设置Cookie, cookie_json                 # 从变量注入
浏览器设置Cookie, D:\in\cookies.json          # 从文件注入
浏览器设置Cookie, D:\in\cookies.json, .example.com   # 缺省域名兜底
浏览器设置Cookie, sid=abc; lang=zh-CN         # 字面量 header 串
```

- **来源解析顺序**：文件路径（存在时）→ 变量名 → 字面量串。
- 支持 JSON 数组 / Netscape（制表符 7 字段）/ `k=v; k2=v2` 三种输入。
- 第 2 参数为「域名兜底」：为未带 `domain` 的 Cookie 补该域名。
- 未解析到任何有效 Cookie 时写 `COOKIE_ERROR`。

> 典型用途：复用登录态（先导出、后在另一次会话注入）、配合抓包导出 Cookie。

## 8. iframe 与标签页（P1）

**iframe**

```text
浏览器点击, #open-dialog
切换框架, #payment-iframe       # DSL 定位进入
切换框架, 2                     # 或按第 N 个 frame（0 基）
切换框架, main                  # 回到顶层（同义：主文档 / 顶层 / top）
等待元素, tag:input@name=cardno, 10, 可见
浏览器输入, tag:input@name=cardno, ${card_no}
返回主框架                       # 等价 切换框架, main
```

- 切换成功后，**后续所有浏览器命令自动作用于当前 frame**（Playwright 的 `Frame` 与 `Page` 共享定位 / 求值 API）。
- 例外：`浏览器截图` 的视口 / 整页、`打开网页`（导航）、`等待元素` 的 `url`/`title` 状态**始终作用于顶层页**。
- `切换框架` 失败时**保持原 frame 上下文不变**；未显式切换时行为与既有完全一致（可随时 `返回主框架` 复位）。

**标签页**

```text
打开网页, https://example.com
新建标签页, https://example.com/report   # 可空=空白页；切换为新页
切换标签页, 0                            # 按序号(0基)
切换标签页, 报表                          # 或按标题 / URL 包含匹配
关闭标签页                                # 关当前（缺省）
关闭标签页, 1                            # 或关指定序号
```

- 新建 / 切换 / 关闭后自动刷新 `browser_url` / `browser_title`。
- 关闭活动页时自动回退到最后一个剩余页；无剩余页则下次命令重新懒启动。

## 9. 下载与上传（P1）

**下载 —— 等待下载**

```text
浏览器点击, text:下载报表
等待下载, D:\out, 报表, 30, dl_path      # 目录, 文件名匹配, 超时(秒), 写回变量
```

| 参数 | 说明 |
| --- | --- |
| ★保存目录 | 缺省用 `browser_download_dir`（空则程序目录同级 `downloads/`） |
| ★文件名匹配 | 包含匹配；`/.../` 包裹视为正则；空 = 任意 |
| ★超时秒数 | 缺省 `browser_download_timeout`（默认 `15.0`） |
| ★写回变量 | 保存后的**绝对路径**（缺省 `浏览器下载路径`） |

- 实现为 **session 级下载事件队列**：DSL 为行式命令，「触发下载」与「等待下载」通常分两条命令，无需把触发动作包进上下文。
- 同名文件是否覆盖由 `browser_download_overwrite`（默认 `True`）控制；置 `False` 时自动避让为 `name_1.ext`。
- 「触发下载」的动作需在前一步完成（如 `浏览器点击, text:下载`）。

**上传 —— 浏览器上传**

```text
浏览器上传, tag:input@type=file, D:\发票\a.pdf, D:\发票\b.pdf
```

- 定位指向 `input[type=file]`；至少一个本地文件路径（支持 `${变量}`），多文件传给 `set_input_files` 列表。
- 末尾若为 `是` / `否` 视作「是否清空已有」开关（Playwright `set_input_files` 本体为替换语义）。
- 文件不存在 → `INVALID_ARGUMENT`。

## 10. CDP 接管已开浏览器（P2）

```text
连接已开浏览器                              # endpoint 取自配置 browser_cdp_endpoint
连接已开浏览器, http://127.0.0.1:9222       # 或显式给出
连接已开浏览器, 127.0.0.1:9222, 否          # 不关闭旧会话（复用已连接的 CDP 会话）
```

**获取 endpoint（Windows）**：以**独立 user-data-dir** 启动带调试端口的浏览器：

```text
chrome.exe --remote-debugging-port=9222 --user-data-dir="D:\cdp-profile"
```

- 须用独立 `--user-data-dir`，否则已开实例不会开启调试端口。
- 可用 `http://127.0.0.1:9222/json/version` 验证端口已就绪；endpoint 填 `http://127.0.0.1:9222`。
- 接管后 `打开网页` 等命令作用在接管的页面上；已在 CDP 模式时再次调用会**复用**（不重复连接）。
- 端口不通 / 非 CDP 端点 → `CDP_CONNECT_FAILED`；endpoint 与配置均空 → `INVALID_ARGUMENT`。

## 11. 接口监听 / 抓包（P2）

```text
开始监听, /api/login, xhr                    # URL匹配, 资源类型
浏览器点击, text:登录
等待数据包, /api/token, 1, 20, token_json    # 匹配, 数量, 超时(秒), 写回变量
停止监听
```

- **开始监听**：对当前页注册响应监听，命中过滤后入队。URL 匹配默认**包含**，`/.../` 包裹为正则；资源类型可给 `xhr`/`fetch`/`document`/`script`/`image`/`stylesheet`/`font`/`media`/`websocket`/`manifest` 等（中文同义如 `接口`→xhr、`文档`/`页面`→document；空 / `全部` / `所有` / `all` / `*` = 不过滤）。
- **等待数据包**：从队列取 / 等待命中数据包；**去重键 = `method + url + status`**；数量可累计多次取回；结果写成 **JSON 列表** 写回变量，给定导出路径则落盘（格式默认 `json`）；超时 → `TIMEOUT`。
- **队列上限** `browser_listen_max`（默认 `200`）**超出丢弃最旧**，防止长跑脚本内存膨胀。
- **不采集 body**：仅采集响应元数据（`url` / `status` / `method` / `resource_type` / `headers`）。如需 body，可对命中的 `url` 再用 `浏览器执行JS` 取。
- **停止监听** 移除监听并清空队列（幂等；未监听时同样成功）。

> 典型用法：`开始监听` 命中登录 / token 接口 → `等待数据包` 取回 JSON 写变量 → `浏览器执行JS` 解析 token → `浏览器设置Cookie` / 后续请求复用登录态。

## 12. codegen → DSL 录制（P2）

```text
启动浏览器录制
```

- 调用 `playwright codegen` CLI 打开录制窗口，结束后把生成的代码**自动转为 ACRPA DSL** 并追加到脚本录制动作（与键鼠录制同一通道）。
- **依赖 playwright CLI**：未安装时命令降级为 `RECORD_ERROR`，提示手动执行 `playwright codegen -o rec.py`。
- 转换器本体 `codegen_to_dsl` 为**纯函数**（不依赖 playwright、不触网），可离线使用；未识别的调用进入告警清单（strict 模式抛 `CONVERT_ERROR`）。

映射示例（节选）：`page.goto` → `打开网页`；`page.click` / `locator.click` → `浏览器点击`；`page.fill` → `浏览器输入`；`page.press` → `浏览器点击` + `按键`；`frame_locator` → `切换框架` + 子定位；`page.expect_download` → `等待下载`；`page.screenshot` → `浏览器截图`；`page.wait_for_timeout(ms)` → `等待`（秒）。

## 13. 常见失败短语与排查

失败时统一写入 `browser_last_error`（code）与 `browser_last_message`（描述），并在日志输出。

| code | 触发场景 | 排查建议 |
| --- | --- | --- |
| `PW_NOT_INSTALLED` | playwright 未安装或浏览器会话不可用 | 执行 `pip install playwright && playwright install chromium` |
| `NAV_FAILED` | `打开网页` 导航失败 | 检查 URL、网络、证书；必要时先用本机浏览器验证可达 |
| `INVALID_LOCATOR` | 定位表达式无法解析 | 对照第 5 节语法表；空串 / 残缺前缀（如 `text:`）会直接失败 |
| `ELEMENT_NOT_FOUND` | `浏览器点击` / `浏览器输入` 未找到元素 | 降低定位依赖（优先 `testid:` / `role:`），或在前面加 `等待元素` |
| `TIMEOUT` | 等待超时 | 增大超时；确认状态选对（如把 `出现` 换成 `存在` / `可点击`） |
| `INVALID_ARGUMENT` | 参数缺失 / 非法（含状态未知、`download`/`navigation` 预留） | 补全必填参数；状态改用具名状态 |
| `JS_ERROR` | JS 执行抛错 | 先在浏览器控制台验证脚本；表达式模式用 `是` |
| `COOKIE_ERROR` | Cookie 导出 / 注入失败或格式未知 | 检查格式取值与来源是否有效 |
| `SCREENSHOT_ERROR` | 截图失败 | 检查保存路径可写、元素是否存在 |
| `BROWSER_DISCONNECTED` | 等待过程中页面 / 浏览器断开 | 确认浏览器未被手动关闭 |
| `FRAME_NOT_FOUND` | `切换框架` / `返回主框架` 未找到目标 frame | 先用 `等待元素` 等 iframe 出现；确认索引 / 定位表达式正确 |
| `TAB_NOT_FOUND` | `切换标签页` / `关闭标签页` 未命中 | 检查序号（0 基）或标题 / URL 匹配串 |
| `TAB_FAILED` / `TAB_CLOSE_FAILED` | 新建 / 关闭标签页失败 | 确认浏览器会话仍存活 |
| `DOWNLOAD_TIMEOUT` / `DOWNLOAD_ERROR` | `等待下载` 超时 / 落盘失败 | 确认已触发下载、目录可写、文件名匹配正确 |
| `UPLOAD_ERROR` | `浏览器上传` 设值失败 | 确认定位指向 `input[type=file]`、文件存在 |
| `CDP_CONNECT_FAILED` | `连接已开浏览器` 端口不通 / 非 CDP 端点 | 核对 `--remote-debugging-port` 与独立 `user-data-dir` |
| `LISTEN_ERROR` | `开始监听` / `等待数据包` 注册或导出失败 | 确认监听已启动、导出目录可写 |
| `RECORD_ERROR` | `启动浏览器录制` CLI 不可用 | 安装 playwright CLI 或手动 `playwright codegen -o rec.py` |

**相关配置项**（`config.json`，默认值均不改变既有行为）：

| 键 | 默认 | 含义 |
| --- | --- | --- |
| `browser_headless` | `true` | 无头模式 |
| `browser_slow_mo` | `0` | 操作慢放（毫秒） |
| `browser_wait_timeout` | `15.0` | 通用等待超时（秒） |
| `browser_poll_interval` | `0.2` | 轮询间隔（秒） |
| `browser_full_page_screenshot` | `false` | 视口截图缺省是否整页 |
| `browser_js_timeout` | `15.0` | 执行 JS 超时（秒） |
| `browser_retry` | `1` | 点击 / 输入瞬态重试次数 |
| `browser_retry_interval` | `0.5` | 重试间隔（秒） |
| `browser_silent` | `false` | 静默模式（预留） |
| `browser_download_dir` | `""` | 下载目录（空 = 程序目录同级 `downloads/`） |
| `browser_download_timeout` | `15.0` | `等待下载` 缺省超时（秒） |
| `browser_download_overwrite` | `true` | 同名下载文件是否覆盖（`false` 自动避让） |
| `browser_screenshot_dir` | `""` | 截图目录覆盖（空 = 沿用 `screenshots/`） |
| `browser_cdp_endpoint` | `""` | CDP 接管地址（如 `http://127.0.0.1:9222`） |
| `browser_listen_max` | `200` | 监听队列上限（超出丢弃最旧） |
| `browser_listen_default_timeout` | `15.0` | `等待数据包` 缺省超时（秒） |
| `browser_user_agent` | `""` | 自定义 UA（与 Cookie 同步配合，预留） |
