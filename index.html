CORE FEATURES

核心特性

从基础自动化到智能工作流，ACRPA 覆盖桌面自动化的完整链路。

📦

Excel 脚本驱动

以 .xls 表格作为脚本文件，A 列命令、B–J 列参数，无需编程即可编排自动化流程，学习成本极低。

🖱

图像识别定位

基于 OpenCV / Pillow 的图像识别，支持全屏与区域找图、灰度加速匹配，精准定位并点击任意界面元素。

🪟

窗口管理

直接操作 Windows 窗口：激活、关闭、最小化、等待窗口出现/消失，支持窗口相对坐标，比图像识别快 10–100 倍。

🎬

录制回放

录制鼠标键盘操作（含拖拽、滚轮、窗口激活），自动插入等待间隔，一键回放，重复操作从此告别手工。

⏱

定时任务

支持每天 / 每周 / 间隔 / 一次性多种调度模式，后台静默执行，配合系统托盘与 Mini Bar 常驻运行。

⚡

DD 驱动增强

可选内核级高性能输入后端，模拟真实键鼠、难以被检测，支持 direct / simulate / auto 三种写入模式并自动回退。

🧩

工作流编排

多脚本串联编排，可视化流程图（节点 / 连线 / 拖拽），支持脚本、并行、条件、等待四种步骤类型。

📊

变量系统

设置变量、读取剪贴板、字符串截取/替换、数学运算，${var} 语法贯穿全程，处理复杂数据得心应手。

🔍

OCR 识别

屏幕区域文字识别、等待文字出现、点击文字，兼容 PaddleOCR / Windows OCR / Tesseract，动态界面也能自动化。

🐞

专业调试器

断点 / 条件断点、单步执行、变量监视器、调用栈、执行耗时统计、运行到光标、跳过行，问题一目了然。

🌓

深色模式

亮 / 暗主题一键切换；系统托盘、Mini Bar 悬浮状态条，让自动化任务在后台安静地跑。

📜

日志与市场

结构化分级日志、按日轮转、自动清理、一键导出；内置脚本市场（离线模式可用），持续扩展脚本生态。

🔄

自动更新

启动自检新版本，多源降级获取清单（GitHub Releases → 原始清单 → CDN 镜像）；下载带进度与 sha256 校验，镜像返回旧包自动换源，一键重启完成替换，不动配置与脚本。v0.1.27

🌐

浏览器自动化

内置 Playwright 网页操作：打开网页、点击、输入、等待元素、整页 / 元素截图，桌面流程与网页流程可串在同一条脚本里。

🛡️

安全守护

失控保护（鼠标徒手甩动即中止）、最长执行时间限制、出错即停与失败重试策略，无人值守也能安全收尾。

TECH STACK

技术栈与运行环境

轻量冷启动，占用小；提供 exe 免安装版本与源码运行两种方式。

🧰 技术栈

Python 3.7+ tkinter PyAutoGUI OpenCV Pillow pywin32 DD 驱动 PaddleOCR Windows OCR Tesseract AI API Playwright

打包为单文件 exe，双击即用；无 OpenCV 时自动降级为 Pillow 匹配，稳而不崩。

⚙️ 关键配置（config.json）

dark_mode 亮 / 暗主题切换
retry_max / retry_interval 失败重试次数与间隔
image_timeout 识图超时秒数
api_key / api_model AI 密钥与模型选择
use_dd_driver DD 驱动高性能输入
minimize_to_tray / mini_bar_enabled 托盘常驻与折叠状态条
sched_enabled / sched_tasks 定时任务调度
log_level / log_retention_days 日志级别与保留天数
stop_on_error / failsafe 出错即停与失控保护
check_update / app_protect 启动自检更新与进程守护
