# 快速开始

- 脚本以**表格**编写，一行一条命令，第一列为命令名，其后各列为参数。
- 图片资源放在脚本同目录，命令中直接写**图片名**即可（也可写绝对路径）。
- 运行前请确保目标窗口**可见**，避免遮挡导致找图失败。
- 支持 `.xls` 与 `.xlsx`（`.xlsx` 需安装 `xlrd`）；另支持 **`.acrpas`（JSON 一等格式）**，可与 `.xls` 互相转换，便于纳入版本管理与脚本生成。
- 执行与调试：`F5` 运行、`F6` 暂停/继续、`F10` 单步、`Shift+F5` 取消。
- 遇到问题请先查看「常见问题 FAQ」章节。

> 提示：在「命令速查」章节可查看全部可用命令及其参数说明（由注册表实时生成）。

## 命令库（`Ctrl+K`）

在脚本编辑区按 `Ctrl+K` 打开**命令库**：按领域分组列出全部命令，输入关键字即模糊过滤（名称精确 > 名称前缀 > 名称包含 > 说明包含），上下键选择、回车把命令写入当前行（无选中行时新增一行）。

## 无头运行（CLI）

给 `run.py` 传入 `--script` 即进入**无头模式**（不创建任何窗口），适合 CI 与批量调度：

```bat
python run.py --script x.acrpas --var n=21 --json-report out.json --exit-code
```

- 省略 `--script` 则照常启动图形界面；
- 退出码：`0` 成功；给了 `--exit-code` 且脚本失败为 `1`；用法错误为 `2`；
- 无头模式使用 schema 默认值（**不读 `config.json`**）以保证结果确定；依赖桌面会话的命令（找图 / 键鼠 / 窗口操作 / OCR / 浏览器）不可用。

## 可选依赖扩展

命令可能依赖**可选能力**（例如 OpenCV 图像匹配）。若该能力未就绪，命令下拉会显示 `⚠` 角标；到「设置 → 扩展」卡片可**安装 / 卸载 / 启用 / 禁用 / 修复**。

> 启用与禁用**无法热插拔**，需重启应用后生效。

## 工作流控制流图

工作流 Tab 的画布是**控制流图**视图：

- 分层布局，分支与汇合并列可见；条件为菱形双出口，循环为范围框 + 回边；
- 从节点**端口拖拽**即可连线，点选连线后按 `Delete` 删除；
- `F` 适应窗口、`Ctrl+0` 重置缩放、`Ctrl+滚轮` 缩放、中键拖拽平移、`Ctrl+Z` / `Ctrl+Y` 撤销重做；
- 画布下方**检查面板**实时汇总静态问题（不可达 / 孤立 / 悬挂出口 / 循环风险 / 路径爆炸 / 环路复杂度）。

> 说明：图编辑为**视图级**（执行仍走树执行器），当工作流结构变化会重新提升为图，视图内的临时连线编辑随之重置。

## 界面缩放与可达性

- 字号与尺寸由统一 Token 派生，「设置 → 系统」的界面缩放会同时影响窗口与字号；
- 标题栏图标（置顶 / 折叠 / 主题 / 设置 / 帮助 / 互联）可用 `Tab` 聚焦，`Enter` 或空格激活。
