# 脚本编辑

## 表格约定

- 每行一条命令，列以 `|` 分隔；第一列为命令名，其后各列为参数。
- 以 `#` 开头的行视为注释，执行时忽略。
- 条件与循环使用成对命令表达：`如果` / `否则` / `结束如果`、`循环开始` / `循环结束`。

## 下载脚本编辑模板

- ACRPA 内置一份**脚本编辑模板**（`.xlsx`）：内含命令类型与参数的下拉选项、常用预设指令、分组配色与多个说明页，便于快速编写脚本。
- 点击帮助窗口顶部的【下载模板】按钮，在弹出的「另存为」对话框中选择保存位置，即可导出这份模板。
- 填写完成后，把文件**另存为 `.xls`**（Excel 97-2003 工作簿）保存到脚本目录，即可被 ACRPA 直接载入执行。

## 命令库

- 在编辑区按 `Ctrl+K` 打开**命令库**：按领域分组、模糊搜索全部命令，回车写入当前行（无选中行时新增一行）。
- 命令的参数说明见「命令速查」章节。

## Excel 说明

- 支持 `.xls`（原生）与 `.xlsx`（依赖 `xlrd`）。
- 图片路径既可用绝对路径，也可写相对脚本目录的**图片名**。

## 代码命令

- `代码`：执行脚本目录下的 `txt` / `Python` 文件（受权限与 AST 预检约束）。
- `Python`：内联执行代码，权限可选 `sandbox` / `trusted` / `full`。

详见 [Python 扩展使用说明](docs/python扩展使用说明.md)。
