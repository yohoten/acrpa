# 执行控制

执行控制 Tab 提供运行、调试与录制能力：

- **运行 / 暂停 / 恢复 / 停止**：控制脚本执行生命周期。
- **单步执行**：逐条执行命令，便于定位问题（`F10`）。
- **录制**：记录鼠标键盘操作并回放为脚本。
- **执行日志**：实时查看每条命令的执行结果与失败原因。
- **步骤级失败策略**：单行可单独指定「停止 / 继续 / 跳转到第 N 行」，覆盖全局「出错即停」。

## 步骤级失败策略

脚本行的右键菜单 → **失败策略...** 可为该行单独指定失败后的走法，默认仍是「跟随全局」。

| 策略 | 角标 | 该行命令失败时 |
| --- | --- | --- |
| 默认(跟随全局) | 无 | 沿用「执行参数」里的 `出错即停`（开=停止，关=继续） |
| 停止 | `⊘` | 立刻停止整个脚本（等价旧的全局停止） |
| 继续 | `↷` | 只记一条告警，继续执行后续行 |
| 跳转到行 | `⇥N` | 跳到第 N 行继续执行（N 为序号列显示的 1 起算行号） |

要点：

- **不新增常显列**：策略存在行元数据里，只在 `#0` 序号列尾部显示一个角标（`01 ⊘` / `02 ⇥12`），行高与列宽不变。
- **失败仍会被记录**：用「继续」跑完的脚本整体仍判定为失败（`browser_last_error` / 执行统计 / 失败现场留存照旧），只是不再中止后续步骤。
- **跳转护栏**：跳转目标非法（越界 / 指向本行 / 未填）会降级为「停止」并写日志；同一目标被反复跳中超过 20 次判定为环，强制停止，避免脚本挂死。
- **循环体内**：只支持「停止 / 继续」；「跳转」在循环体内不生效（跨块语义不明确），会按「停止」处理并提示。
- **持久化**：`.acrpas` 存进 `rows[i].on_error` / `jump_to`；`.xls` 存进第二张工作表 `ACRPA-Policy`（主表仍是 10 列，旧版本打开完全不受影响）。
- **撤销/重做**：策略随行快照一起进出 undo 栈；复制粘贴 TSV 只带 10 列，策略不随之复制（避免把上一行的失败策略误带到别处）。

完整设计说明见 [执行控制 tab 设计方案](docs/执行控制tab设计方案.md)。
