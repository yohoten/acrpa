# 工作流

工作流用于把多个脚本按顺序编排执行：

- `运行工作流`：调用工作流文件（`.json`）执行多脚本编排。
- `工作流变量`：设置工作流级共享变量，供各子脚本读取。
- 支持别名、顺序 / 并行执行与错误传播（`stop_on_error`、重试）。

## 控制流图（CFG）

工作流 Tab 的画布是**控制流图**视图，而不是单纯的节点列表：

- **分层布局**：按依赖分层（Sugiyama 简化版），分支与汇合并列可见；
- **形状语义**：开始 / 结束（圆角）、脚本、命令、条件（菱形双出口）、并行（容器框）、循环（范围框 + 回边）；
- **连线交互**：从节点**端口拖拽**连线；端口类型不匹配或重复连线会被拒绝；点选连线后按 `Delete` 删除；成环的连线自动标记为回边；
- **视图操作**：`F` 适应窗口、`Ctrl+0` 重置缩放、`Ctrl+滚轮` 缩放、中键拖拽平移、`Ctrl+Z` / `Ctrl+Y` 撤销重做。

> 说明：图编辑为**视图级**（执行仍走树执行器）；当工作流结构变化会重新提升为图，视图内的临时连线编辑随之重置。

## 静态检查面板

画布下方实时显示检查摘要，覆盖：

- 不可达步骤（从入口无法到达）；
- 孤立步骤（无入边也无出边）；
- 条件分支缺少出口边；
- 之后没有出口的步骤；
- 循环风险（次数为空 / 条件循环体内未修改变量）；
- 重复连线；
- 入口→出口路径数过多（建议拆分）；
- 环路复杂度超阈值。

> 工作流命令与引擎能力均来自运行时，详见「命令速查」中的「工作流」分组。
