# 浏览器自动化

基于 Playwright 的浏览器自动化，使用前需 `pip install playwright` 并安装浏览器内核。

- **基础操作**：`打开网页` / `浏览器点击` / `浏览器输入` / `等待元素` / `浏览器截图`。
- **P0 增强**：`浏览器执行JS` / `执行JS` / `浏览器读取Cookie` / `浏览器设置Cookie`。
- **P1 增强**：`切换框架` / `返回主框架` / 标签页管理 / `等待下载` / `浏览器上传`。
- **P2 增强**：`连接已开浏览器`（CDP 接管）/ `开始监听` / `等待数据包` / `停止监听` / `启动浏览器录制`。
- **滑块验证码**：`浏览器验证码` —— 缺口偏移测算（缺口包围盒几何法优先，退化到背景图灰度列差分）+ 鼠标分段缓动拖拽 + 成功检测/刷新重试。仅用 PIL 与 Playwright 公开 API 自行实现，不依赖任何第三方 OCR/OpenCV 组件，也不内置浏览器内核。

  ```text
  浏览器验证码, #slider-btn, #captcha-bg
  浏览器验证码, .yidun_slider, .yidun_bg-img, , .yidun_tips--success, .yidun_refresh
  浏览器验证码, #btn, .bg, .gap, .ok, .refresh, 1000, 40, 2, 8
  ```

  参数：滑块定位, 背景图定位, 缺口图定位(可空), 成功检测定位(可空), 刷新定位(可空),
  拖动时长ms(默认800), 拖动步数(默认30), 偏移修正px(默认0), 校验超时秒(默认5)。
  重试次数取配置项 `browser_retry`（默认 1，即最多尝试 2 次）；位移结果写入变量
  `browser_captcha_offset`。**合规提示：仅用于自有系统/已获授权的自动化场景。**

详见 [浏览器使用说明](docs/浏览器使用说明.md) 与 [浏览器后端增强设计](docs/浏览器后端增强设计.md)。
