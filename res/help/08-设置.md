# 设置

设置窗口左侧导航包含以下分类（**静态镜像**，须与 `src/ui/settings/window.py` 的 `_NAV_ITEMS` 保持一致）：

- 基础执行
- AI 增强
- 定时调度
- 录制设置
- 日志
- 系统
- 快速操作
- 高级设置
- 网络互联
- Python 扩展
- 脚本市场
- **扩展**（安装 / 卸载 / 启用 / 禁用 / 修复可选依赖扩展）

> 说明：内容层不得引入 tkinter，故此处为静态列表而非运行时派生；
> 若设置窗口导航项有调整，请同步更新本文件与 `sections.json` 的 `source` 字段。

## 保存与反馈

- 卡片内的改动会在约 600ms 防抖后**自动保存**（无需手动点「确定」）；
- 保存失败时，卡片标题栏角标会变为「⚠ 保存失败 (点击查看)」，点击可查看原因并重试；
- 「扩展」卡的**启用 / 禁用无法热插拔**，需**重启应用**后生效。
