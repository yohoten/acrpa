# 常见问题 FAQ

## 为什么找图总是失败？

- 确认目标图片与脚本同目录且命名一致。
- 适当降低精度（默认 `0.96`），或改用「区域找图」缩小范围。
- 确保目标窗口**可见**且未被其他窗口遮挡。

## 脚本无法读取 Excel？

- `.xlsx` 需要安装 `xlrd`；建议优先使用 `.xls`。
- 检查文件是否被其他程序占用。

## 运行没有反应？

- 检查是否处于暂停状态；查看「执行日志」定位失败命令。
- 确认已授予必要权限（如 `Python` 命令的 `sandbox` / `trusted` / `full`）。

## 命令下拉里的 `⚠` 是什么？

- 表示该命令依赖的**可选能力未就绪**（未安装 / 装了但自检失败 / 被禁用）。到「设置 → 扩展」安装或修复；启用 / 禁用需重启应用后生效。

## 想在没有桌面的环境里跑脚本？

- 用无头 CLI：`python run.py --script x.acrpas --json-report out.json --exit-code`，详见「快速开始 → 无头运行（CLI）」。
- 依赖桌面会话的命令（找图 / 键鼠 / 窗口操作 / OCR / 浏览器）在无桌面环境下不可用。
