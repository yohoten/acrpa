# 快捷键

## 全局快捷键（可在「设置 → 高级设置」中自定义）

- `F5`：执行默认配置（配置项 `hotkey_run`）
- `F10`：单步执行
- `F6`：暂停 / 继续执行（配置项 `hotkey_pause`）
- `Shift+F5`：取消执行（配置项 `hotkey_stop`）
- `Alt+Shift+F4`：强制关闭
- `Ctrl+Shift+A`：截图

> 三个可配置快捷键对应 `state` 配置项 `hotkey_run` / `hotkey_pause` / `hotkey_stop`，
> 留空表示使用应用内置默认绑定（默认值以上表为准）。

## 脚本编辑区（不可配置）

- `Ctrl+K`：命令库（按领域分组 + 模糊搜索，回车写入当前行）
- `F2`：编辑当前行（命令下拉 + 参数表单）
- 双击单元格：就地编辑
- `Ctrl+D`：复制选中行；`Delete`：删除选中行
- `Ctrl+/`：注释 / 取消注释选中行
- `Alt+↑` / `Alt+↓`：上移 / 下移选中行
- `Ctrl+C` / `Ctrl+V`：复制 / 粘贴选中行
- `Ctrl+Z` / `Ctrl+Y`：撤销 / 重做
- `Ctrl+鼠标滚轮`（或 `Ctrl+=` / `Ctrl+-`）：编辑器字号缩放；`Ctrl+0`：复位字号

## 工作流画布（不可配置）

- `Ctrl+滚轮`：以光标为锚点缩放（0.4×–2.5×）；`Shift+滚轮`：水平滚动；中键拖拽：平移
- `F`：适应窗口；`Ctrl+0`：重置缩放
- 从节点端口拖拽到另一节点：建立连线；点选连线后 `Delete`：删除该连线
- `Ctrl+Z` / `Ctrl+Y`：撤销 / 重做图编辑
