## 8. 漂移守卫（`--check`）行为

- 默认目标文档为根目录 `使用说明.txt`（`--check [PATH]` 可指定）。
- 解析文档命令区：取每行**首个空白分隔 token**为命令名（生成的分组表每行首 token 即命令名）。
  如此可避免 `一：找图（…）`、`找图：…` 等旧写法被误判命中，守卫真正能发现「文档漏命令」。
- 校验 **注册表命令集合 ⊆ 文档命令名集合**：
  - 缺失 → 打印 `[FAIL]` 列出缺失命令名，返回码 **非 0**；
  - 全部命中 → 打印 `[OK]`，返回码 **0**。

实测：
- 打补丁**前**：`[FAIL] 文档缺失 68 条命令: …`（返回码 1）。
- 打补丁**后**：`[OK] 注册表命令集合 ⊆ 文档命令名集合（文档未漏命令）`（返回码 0）。
